Built 2026-09-23 at the user's request ("translate equations of functions into closed-form
outputs", reusable for future modelling).

- `Warehouse/kernel/closed_form.py` (stdlib only; kernel modules may not import each other, so
  cost-law equations live here and mirror `cost_model` by name). Expression tree
  (Sym/Const/Fn/Piecewise/Sum/Call) -> `.evaluate`, `.latex(env)`; `Model` composes by symbol
  (toposort, cycle raises), `to_markdown(result)` prints each equation from its own tree with
  numbers substituted, `to_dot`, `sweep`. `Law` = model bound to an object's coefficients.
- Mirror gate: `register('pkg.name', Equation(..., mirrors=Mirror('mod:fn', args, domain)))`;
  `Tests/unit/test_closed_form.py` draws inputs and holds the equation equal to the function.
  A NEW declaring module must be added to its `DECLARING_MODULES`.
- Class attributes: `PickConfig.closed_form`, `PutawayCost.closed_form`, `UnloadCost.closed_form`
  (outputs at_location / put / unload), pinned by `Tests/unit/test_cost_laws.py`.
- Composed models: `Optimization/simconfig/models/levels.py`, `Optimization/simconfig/models/reorders.py`,
  `Optimization/simconfig/models/churn.py`; a non-algebraic closed form enters as a `Call` node,
  never re-implemented.
- Visuals: `Optimization/Performance_Evaluations/closed_form/render.py` (model_graph,
  sweep_chart, predicted_vs_realised, write_page). `docs/closed-form-models.md` is GENERATED by
  `python -m Optimization.Performance_Evaluations.closed_form.docs_page --write`; a model edit
  fails `test_closed_form_render.py` until regenerated.
- Run-scope analysis: `closed_form.predicted` writes the contract's `closed_form_json` /
  `closed_form_pngs` into the dossier (run-tree schema d9ffe4d51503).
