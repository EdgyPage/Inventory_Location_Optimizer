def drain_records(self) -> list
This batch's unload records, and start the crew's clock over. A DRAIN IS A BATCH BOUNDARY, for the same reason `drain_putaway_records` is: the records carry `t0` on the crew's own clock measured from the start of the batch, because the batch epoch is not known here -- receiving runs at the TOP of the batch, before the pickers have been simulated. The runner adds the epoch when it writes the rows. Resetting is load-bearing, not tidiness: without it the clock accumulates across the whole arm while the runner still adds the epoch, and every row after batch 0 is stamped too late by the total receiving seconds of every preceding batch.
