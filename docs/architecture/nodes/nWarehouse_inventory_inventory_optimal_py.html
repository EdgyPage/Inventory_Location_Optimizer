Warehouse.inventory.inventory_optimal
inventory_optimal.py — optimal layout, Σf·D objective, full-labor floor + optimal map. `OptimalLayoutMixin` holds the benchmark/optimal-placement methods. Mixed into Inventory_Manager so the public API (`place_optimal`, `optimal_sigma_fd`, `optimal_work`, `build_optimal_map`, `current_sigma_fd`, `enable_sigma_fd`, `tracked_sigma_fd`) is unchanged. All instance state it reads (`self._key`, `self._execute_placement`, `self._originals`, `self._unavailable`, `self._bin_pref`, `self._map_target`, `self._sigma_*`) is initialised by Inventory_Manager.__init__.
