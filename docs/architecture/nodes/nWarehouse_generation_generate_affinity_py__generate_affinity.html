def generate_affinity(group_skus: dict[str, list[int]], sku_demand: dict[int, tuple[float, float]], min_lift: float, max_lift: float, noise_std: float, top_k: int, candidate_k: int, rng: random.Random, conn: sqlite3.Connection, cluster_size: int=_CLUSTER_SIZE_DEFAULT, batch_size: int=500000) -> dict
Generate latent-cluster top-K affinity pairs and insert to the DB. Within each group, SKUs are partitioned into random clusters (independent of demand); each SKU's top-k same-cluster partners are stored with a random association strength in (min_lift, max_lift]. Both (i→j) and (j→i) are inserted with the same lift; INSERT OR IGNORE skips pairs already stored. Returns per-group statistics for stats.json and plots.
