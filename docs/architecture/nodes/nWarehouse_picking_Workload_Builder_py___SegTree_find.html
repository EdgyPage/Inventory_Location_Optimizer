def find(self, u: float) -> int
0-based index of the leaf the weighted draw `u` lands on. Branches right only when the right subtree actually holds mass, so every step stays inside a positively-weighted subtree and the returned leaf is guaranteed live. This also makes the call TOTAL: a `u` at or above the root total (`random.uniform` can return its upper bound) walks to the last live leaf instead of off the end.
