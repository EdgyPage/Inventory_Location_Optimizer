def standing_stamps(self) -> list
Rows for every trailer still on site — the CENSORED detention the run ends in. Non-destructive, and deliberately: nothing has finished, so nothing may be forgotten. `emptied_s` is NULL here and that null is the whole point — the detention span of these trailers is right-censored at the run end, not zero. Under an adversarial ordering (`lifo`) this is exactly where the concentrated overage sits, so a table that dropped these rows would report `lifo`'s fee as CLIPPED rather than concentrated, which is the opposite of its signal. Yard and staged alike: a trailer at a door with units still on it has been held just as long as one that never reached one. `staged_s` tells them apart.
