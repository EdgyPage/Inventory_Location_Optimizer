def speed(self) -> SpeedProfile
This picker's travel speeds as one value, ft/s converted to s/inch once. A PROPERTY, not a field, and deliberately: `x_speed`/`y_speed` are a public serialization contract. `run_map_precompute` rebuilds a `PickConfig` from an ARCHIVED `config.json` by filtering `dataclasses.fields`, and `docs/macros.py` reads `c["x_speed"]` to render the published pick-time formula. Both would fall back to defaults SILENTLY if the fields were replaced — and no canary would catch it, because none of them reads an archived config. So the pair stays exactly where it is and this is the derived view of it, for the callers that want to hoist one object instead of two floats.
