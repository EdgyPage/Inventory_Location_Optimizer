def _rank_scores(skus: list[int], activity: dict[int, float]) -> tuple[list[int], dict[int, float]]
Return (sorted_skus, rank_score_map), sorted highest-to-lowest activity. rank_score = 1 / sqrt(rank + 1): rank 0 (highest demand) → 1.000 rank 1 → 0.707 rank 3 → 0.500 rank 9 → 0.316 rank 99 → 0.100 rank 399 → 0.050 This gives a realistic Pareto-like spread so high-velocity SKUs are clearly dominant partners without saturating low-velocity pairs at zero.
