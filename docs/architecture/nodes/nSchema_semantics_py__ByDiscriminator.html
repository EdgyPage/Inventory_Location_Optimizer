@dataclass(frozen=True)
class ByDiscriminator
A column whose kind depends on a sibling column's VALUE in the same row. `carryover.qty` is the canonical case: three `reason` values are re-emitted LEVELS and four are FLOWS, sharing one physical column under one PK. Row-free aggregation over such a column is not defined, and every guard here says so rather than guessing.
