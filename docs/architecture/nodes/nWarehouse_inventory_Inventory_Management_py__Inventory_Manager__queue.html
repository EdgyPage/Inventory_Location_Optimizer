layer wh_inventory · file Warehouse/inventory/Inventory_Management.py

def _queue(self, item: 'PutawayItem') -> 'PutawayItem'
Route one STAMPED item to its put queue, holding it if the queue is full. Split out of `_admit` so the receiving crew has somewhere to hand an item it has already taken off a trailer. `_admit` stamps and decides WHERE work enters; this decides which put queue takes it. A dock unload calls this directly -- the item was stamped on arrival and must not be re-stamped.
