function _fifo

layer wh_inventory · file Warehouse/inventory/put_policy.py

def _fifo(item) -> float
Strict arrival order, whatever the placement policy would prefer. Distinct from `k_cap=1`, which also produces arrival order: that constrains the POOL, this replaces it. With `fifo` the pool has no say even at a wide `k_cap`, which is what you want when the constraint is physical (no floor to re-sort on) rather than a tolerance you chose.
