class _LazySeq
A read-once iterator dressed as the `[list, cursor]` slot's list: `len` is known up front and `seq[i]` draws the iterator up to `i`. `_place_merge` reads a slot's list only as `len(lst)` and `lst[cur]` with `cur` rising by one, so a merged tail it stops reading after a dozen units never pays for the thousands it did not reach.
