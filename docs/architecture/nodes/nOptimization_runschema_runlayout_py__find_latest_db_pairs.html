def find_latest_db_pairs(profiles_dir: str) -> list[tuple[str, str, str]]
Return DB pairs from the most recently generated profile run only. "Latest" is `ProfileTree.latest()` — descriptor `created` timestamps for contract runs, the historical lexicographic name order for pre-contract ones, a logged warning when the two disagree. On a tree with no descriptors anywhere this is byte-for-byte the old behavior (the timestamped names make the lexicographic order correct).
