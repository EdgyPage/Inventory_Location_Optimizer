def _tree_for(cell_dir: str)
(RunTree, cell_name) for the run this CELL directory belongs to. The rollup receives a CELL dir (analyze_run calls it once per cell), so the resolver is rooted at the PARENT — where the run descriptor lives — and the cell name is the dir's own basename. A tree with NO descriptor (scratch trees in tests, ad-hoc analyses) falls back to the HEAD contract rooted at the same parent: the head templates render exactly the strings the old hand-joins assumed, so the fallback is behavior-preserving while keeping the shape in one place. A descriptor that names an UNKNOWN schema still fails loudly (resolver_for raises before the fallback is consulted only for the missing-descriptor case).
