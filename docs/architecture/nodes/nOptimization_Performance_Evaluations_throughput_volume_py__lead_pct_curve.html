def lead_pct_curve(hrs, items, base_hrs, base_items, npts=200)
(grid_hours, lead_pct) — this arm's lead over FIFO at matched elapsed time, as a % of FIFO's cumulative at that time. Both curves are interpolated onto a shared grid spanning only the hours BOTH actually cover, so the comparison never extrapolates past the shorter run. Grid points where FIFO has finished nothing yet are dropped (a ratio needs a base).
