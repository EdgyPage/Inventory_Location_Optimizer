def load_counts(path: str, expected_fingerprint: str | None=None) -> dict | None
Return `{sku, counts, bounds, M, seed_batches}` IFF the stored fingerprint matches (or no expectation is given); else None, so a caller falls back to drawing. `counts` is the per-chunk matrix, NOT the total -- summing is the caller's, because the prefix ladder is the reason the chunks are kept apart.
