def drain_trailer_stamps(self) -> list
The site's FINISHED trailer stamps for this batch, and start the list over. Trailer-denominated, so the site's and not a channel's (ADR-0005). Both leaves hold this one transit, so a leaf draining it would take every trailer on the site into its own table and leave the other channel's yard looking empty — which is why `Inventory_Manager.drain_yard_trailers` refuses once the scope is the site's.
