Optimization.Performance_Evaluations.common.painters
Shared figure painters — the builders more than one evaluation draws with. Post-redesign this module holds exactly three things: * `overtime_metrics` / `top_tag` — the shared filename-stem vocabulary. Every over-time figure basename and every `top{n}[_by_{dim}]` suffix in the published site composes from these two functions, so THIS module is where those names are minted (and where the figure-registry test looks for the stems). What each name MEANS — its unit, axis label and direction — comes from `core/quantities.py`; `overtime_metrics` is a projection of that table, not a second copy of it. * `paint_overtime` — the one over-time painter, drawn through chartkit for both its views: 'absolute' (honest units — a data-chosen time unit, items/hour, f·D) and 'percent' (improvement vs the baseline strategy, positive = better). The config-stage trajectories family and the aggregate stage both render with it, which is what keeps their charts visually identical. * unit helpers binding the metric vocabulary to chartkit's unit policy. Everything else the old painters carried (facet grids, top-N line picks, breakdown and delta bars) either died in the redesign or moved into the single family module that owns it now.
