def resolve_base_dir(name: str) -> str
Resolve a CLI run argument: an absolute path as-is, a bare name against COMPARISON_OUTPUT_DIR. Every downstream CLI over a run tree shares this, so `python -m Optimization.run_whatif_delta comparison_20260728_120000` behaves the same as the analysis hub instead of only resolving relative to the current directory.
