def line_moments(orders) -> dict
The first two moments of ONE line's units over a section, weighted the way the sampler weights (a SKU's line share `π_s = freq / Σ freq`), off each SKU's STAMPED line law: `{'m1': E[q], 'm2': E[q²], 'var': Var[q], 'n_skus'}`. `E[q²] = Σ_j (2j + 1) P(q > j)` from `line.survival`, summed to the law's 1 - 1e-12 quantile (the tail past it is below float noise on a Poisson). Zeros on an empty section or a zero weight sum.
