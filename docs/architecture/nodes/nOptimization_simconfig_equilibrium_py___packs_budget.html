function _packs_budget

layer optimization · file Optimization/simconfig/equilibrium.py

def _packs_budget(f_repack: float) -> float
`f_repack` (packs repacked PER PACK RECEIVED) as a pack COUNT for the window. At 0.0 the rate and the count coincide, which is the only value that has ever shipped. Any other value needs the window's received-pack count to convert, and nothing here has it -- so this REFUSES rather than comparing a rate to a count and silently judging a run against a number three orders of magnitude off. Whoever gives `f_repack` a real value writes the conversion here; that is the one line that has to learn it.
