def _require_affinity(affinity, policy: str) -> None
Fail loudly if an affinity-DRIVEN policy (cohesion / co-demand) is built without a usable affinity matrix, rather than silently scoring 0 lift and degrading to uniform. Mirrors the batch sampler's refusal to silently fall back (Workload_Builder.Batch). Travel/ranked policies are exempt: they only use lift as a minor tie-break and rank fine on frequency alone.
