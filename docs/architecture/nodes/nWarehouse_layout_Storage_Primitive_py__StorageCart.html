class StorageCart
Base cart type: the picking container whose volume sets the cart-swap threshold. Subclasses model different cart sizes (see StoreCart / FulfillmentCart) by overriding the dimensions; capacity() reads the volume off the *type* so config/sim code never has to instantiate a cart just to know how much it holds. Add a new cart = new subclass.
