def note_records(self, leaf, finish) -> None
`leaf` has handed its records over and stamped them; `finish` is the absolute instant its last put ended, or None when it recorded nothing. Called once per leaf per site day, on BOTH the picked and the skipped path — a batch that produced no tasks still ran `check_reorders` and may have put hundreds of units away. When the last leaf reports, the shared clocks reset and the site carry is committed: both halves of "the pool resets once per site day, after both leaves have drained". The carry moves only when somebody actually worked. No records anywhere means the crew is where it was, exactly as an unpooled leaf leaves `put_clock` alone.
