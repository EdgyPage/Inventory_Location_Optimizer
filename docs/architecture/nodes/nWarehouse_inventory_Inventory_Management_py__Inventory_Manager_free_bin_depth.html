def free_bin_depth(self) -> int
How many bins are in the free index right now -- a LEVEL, read at batch end. ADR-0003's other half of the record: the own-bin rung fires because this ran to zero, so the share is only readable next to the depth that produced it. Not reset, because a level is not a flow. THE WHOLE GEOMETRY, not the leaf's section: `_index` holds every bucket the warehouse was built with, and a channel leaf simulates one section of it, so this total counts the other channel's untouched bins as free (memory `free-bins-counts-the-whole- geometry`: 57% read where the section's real headroom was 15-18%). It keeps its meaning under its name -- `batch_stats.free_bins` is published -- and the reading a clause can act on is `free_bin_depth_by_bucket`.
