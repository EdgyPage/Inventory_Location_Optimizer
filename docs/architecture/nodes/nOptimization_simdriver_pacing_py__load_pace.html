The pace book for one reference run — `{}` when it has nothing to say. Called ONCE per invocation, before the first cell submits: `load_rows` opens a SQLite file and a per-unit call would reopen it per unit. Best-effort by design. A reference run that cannot be read is a worse dispatch order, never a failed run, so every failure here logs and returns `{}` — which the pool reads as "no weights", which is submission order, which is what it did before this existed.
