def bind(path: str, family: str, *, requires=None, pinned: str | None=None, verify: bool=True, immutable: bool=False) -> 'Dataset'
Open `path` read-only and bind it to ITS OWN schema version. Resolution is stamped -> pinned -> derived (`identity.resolve`); an id the family does not vet raises `UnsupportedSchema` with the structural diff, exactly like `identity.check`. The bound shape is the file's own — the declared shape when the id is current, else the committed document (`UnrecoverableShape` if the store lacks it, which the write-time gates now prevent). `requires` (a `compat.Requires`) is validated against the BOUND shape at bind time, so a consumer fails at open with the missing column named, not mid-analysis with a default 0.0. `immutable=True` is for finished archives only — it skips WAL sidecar creation but the caller must promise nothing is writing (see `Schema.connect.read_only`).
