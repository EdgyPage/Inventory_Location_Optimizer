function _release_site

layer inbound · file Inbound/transit.py

def _release_site(self, now_s: float | None) -> None
Load every order whose supplier lead has elapsed (remaining <= 0), in queue — i.e. fire — order. Called at the top of every `dispatch` and every `release`, so a due order rides the same drain whether or not anything fired that batch. A negative remainder is never clamped, exactly as `BatchTransit` leaves it.
