def _parse_lead_spec(spec, rand_range, freq_profile='uniform') -> tuple
A --lead-times token → (profile_name, lead_time, lead_time_range). 'random' → per-SKU lead ~ randint(rand_range); a number → fixed per-SKU lead. A non-uniform freq_profile (e.g. 'bell') is tagged into the name so its run leaf stays distinct from the uniform baseline (mixed_realistic_bell_lt1 vs mixed_realistic_lt1); 'uniform' keeps the historical names unchanged.
