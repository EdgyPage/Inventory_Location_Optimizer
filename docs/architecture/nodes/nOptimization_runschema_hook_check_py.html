Optimization.runschema.hook_check
hook_check.py — Stop-hook backstop that nudges a run-tree schema resync on drift. Wired via .claude/settings.json (Stop hook), alongside context/arch/hook_check.py. Runs ONLY the cheap stage of the preflight — a source-fingerprint comparison plus a staleness check of the committed contract. It NEVER runs a canary simulation and ALWAYS exits 0: this is advisory and must not block a turn, slow it down, or fail when something upstream is half-edited. The nag it prints is the whole point. Discovering that the output tree moved at the START of the next simulation is cheap; discovering it after a multi-hour run, from broken graphs, is not. Run standalone: python Optimization/runschema/hook_check.py
