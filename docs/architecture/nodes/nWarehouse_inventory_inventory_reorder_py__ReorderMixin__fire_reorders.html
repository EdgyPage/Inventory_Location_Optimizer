def _fire_reorders(self) -> list[int]
Fire Order-Up-To reorders for depleted SKUs into the lead queue. Returns the SKUs triggered and sets `_units_ordered` for the batch. Inventory POSITION = on_hand + queued (stock queue) + deferred (lead queue), so a SKU with an order already in flight is not reordered again.
