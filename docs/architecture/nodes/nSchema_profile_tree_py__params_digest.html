def params_digest(params_json_path: str) -> str
sha256 over the params.json FILE BYTES as written. No canonicalisation, deliberately: the params timestamp participating in the digest is a FEATURE — a regeneration mints a new digest even under identical parameters, which is exactly what makes silent in-place re-pointing detectable from a run's recorded binding.
