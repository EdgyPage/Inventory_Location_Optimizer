class _Cursor
One bucket of a slice: a window into a frozen D-sorted index list that skips excluded bins lazily. Speaks the deque protocol the pools read (`dq[0]`, `dq[-1]`, `popleft()`, `pop()`, truth, `len`) and the bucket protocol (`top()`, `pop_top()`), so a pool's `take` is the same code over a slice as over its own deque or heap.
