def aisle_workload_components(x_traversed: int, y_traversed: int, carts_required: int, pick_lines: list[tuple], params: WorkloadParams) -> tuple[float, float, float]
The (D, P, C) decomposition of one aisle's workload W = D + P + C. D (travel) = x_traversed * sec_per_inch(x_speed) + y_traversed * sec_per_inch(y_speed) (x_speed/y_speed are ft/s; x_traversed/y_traversed are inches walked) P (handling) = Σ_stops height_mult(y) * (intercept + qty * (weight_coef*ln(weight) + volume_coef*ln(volume))) C (cart) = cart_swap_coef * max(0, carts_required - 1) Mirrors Warehouse/Pick._pick_time, including the height-bracket multiplier on the per-unit weight/volume handling. Split out so callers can report the handling-vs-travel breakdown of the analytical objective (see expected_task_labor). Parameters ---------- x_traversed : total bayX distance walked in the aisle (from Task) y_traversed : total bayY distance walked in the aisle (from Task) carts_required : number of carts the aisle's picks fill (from Task) pick_lines : one (weight, volume, qty[, y_phys]) tuple per pick stop params : WorkloadParams coefficients
