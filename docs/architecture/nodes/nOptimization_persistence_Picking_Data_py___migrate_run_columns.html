def _migrate_run_columns(con: sqlite3.Connection) -> None
Add any simulation_runs column this build expects but an older file lacks. ALTER TABLE ADD COLUMN is O(1) in SQLite (it only rewrites the schema), and adding the column also lifts the file's observed shape onto the current declared id — which is exactly what the reader registry wants. Existing rows keep NULL, and a NULL stamp is the documented "derive it" path.
