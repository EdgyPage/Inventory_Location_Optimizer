Visualization.server
server.py — DB-backed replay & compare viewer. Serves finished simulation runs (no live sim) for the web viewer: discover runs by name, warehouse geometry, per-(run,batch) reconstruction, and static per-bin layout scores. All reconstruction is read-only and scoped per request (see db_reader); sim DBs are ~550 MB so nothing loads whole tables. Run base directory resolution (first that exists): --base CLI arg → $COMPARISON_OUTPUT_DIR → ./ (cwd) Endpoints GET / index.html GET /<file> static asset GET /api/runs [{id,label,pair,config,strategy,n_batches}, ...] GET /api/geometry?run=<id> {aisles:[...], grid_cols} GET /api/batch?run=<id>&batch=<b> reconstructed batch payload GET /api/scores?run=<id> {layout:{key:score}, map_pref:{key:score}, has_map, source} GET /api/sku_scores?run=<id> {sku: {map_target, labor_cost, expected_*, ...}}
