Optimization.simdriver.workunits
simdriver.workunits — plan the per-strategy work units for the flat pool. Builds one work unit per (pair, config, channel, strategy) arm: shared assets + batches + resume-aware start planning + the picklable strategy_args dict shipped to each worker. Runs only in the parent process.
