def inbound_spec() -> dict | None
The trailer pipeline's configuration as a picklable record, or **None** for off. None rather than a dict with a flag, for the same reason `recv_crew_spec` returns None: the worker tests `args.get('inbound') is None` and skips the whole build -- no TrailerTransit, no trailer objects, and the manager keeps the batch lead queue it constructed for itself, byte-identically. Reads CONFIG at CALL time (the `recv_crew_spec` pattern, never `put_crew_spec`'s settings snapshot). The lead is authored in MINUTES and converted to the sim's seconds exactly once, here -- the minutes-at-the-surface decision.
