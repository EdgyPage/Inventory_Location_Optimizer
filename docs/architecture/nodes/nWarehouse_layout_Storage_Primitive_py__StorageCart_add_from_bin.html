def add_from_bin(self, bin_: Aisle.Bin, quantity: int) -> int
Take up to `quantity` units of the bin's order into the cart. Assumes perfect packing — placement succeeds if order volume fits in remaining cart volume, regardless of orientation. Returns the number of units actually taken. Clears bin_.storage when its quantity reaches zero.
