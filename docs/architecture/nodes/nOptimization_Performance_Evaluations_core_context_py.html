Optimization.Performance_Evaluations.core.context
EvalContext / AggregateContext — the per-config (and per-aggregate-group) data hub. Built once by the driver and passed to every graph's render(ctx, params). Lazily loads and caches exactly what each graph touches (batch/task frames per strategy, the series dict, the travel/handling breakdown, steady-state cutoffs), so the duplicated per-graph reloading of the old monolith is gone. A graph never reloads a DB the context already holds; it just calls ctx.batch_df(key) / ctx.series() / ctx.breakdown().
