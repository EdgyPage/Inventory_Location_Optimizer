Generate one tiny inventory+affinity pair in the profiles-tree layout the driver discovers. Mirrors Tests/test_channel_runner_smoke.py's catalog: a real (if small) affinity matrix over consecutive SKUs, because affinity-driven arms refuse to run on an empty one. `mixed=False` omits the fulfillment family, which is what makes the run store-only (no `<channel>` level).
