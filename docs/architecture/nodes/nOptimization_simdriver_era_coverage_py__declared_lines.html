def declared_lines(inputs: dict, name: str, section) -> float | None
The DECLARED lines per day of channel `name` over `section`, or None flag-off. The declaration is in the sampler's unit -- the fraction of the section's SKUs drawn per day -- so the line count is `fraction × N` over exactly the orders handed in: the whole catalogue at the seed, the sampled set at stage A. The two agree whenever the planner samples nothing away, which is every run without `--max-skus`.
