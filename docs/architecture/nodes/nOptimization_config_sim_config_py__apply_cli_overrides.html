def apply_cli_overrides(args) -> None
Write every declared knob's CLI value back onto CONFIG['global']. THE write-back. Replaces ~35 hand-typed assignments plus two family loops; a knob that is declared above cannot now be accepted at the command line and then silently ignored for the whole run, which is the defect this registry exists to make unrepresentable. CONFIG is mutated in place and never rebound (see the module head): every accessor reads at call time, so this reaches the warehouse build, the channel build and every worker payload built after it.
