def _identity_matches(log, rec, shared) -> bool
The gate: does the rebuild reproduce what the run recorded about its warehouse? A refusal here is the DESIGNED outcome, not a failure of this script. It already caught the real thing once: without the run's own shaping params applied first, the rebuild produced 5,814 aisles / 6.2 M bins against a run that recorded 384 / 398,500, and the timing taken on it would have been published as if it meant something. `regime_bins` is deliberately not checked: it is the per-CHANNEL slice, and the whole warehouse is what the map is built over.
