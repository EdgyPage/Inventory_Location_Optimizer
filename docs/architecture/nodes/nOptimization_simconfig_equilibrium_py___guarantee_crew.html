function _guarantee_crew

layer optimization · file Optimization/simconfig/equilibrium.py

def _guarantee_crew(section: dict, pickers: int, S: float) -> dict | None
The stamped guarantee's crew block (ADR-0004) as the labour clause reads it, or None on a record that predates it: `{'pickers', 'load_s', 'sd_s', 'cut_share', 'cut_share_sd'}`. `cut_share` is the stamped expectation; `cut_share_sd` is derived from the same law (`staffing.cut_share_sd`) so the band around it is the law's, not a typed number. The crew in the block is the solved K; `pickers` (the derived crew off `channel_crew`) is the same number on every record `derive` wrote, and is what the sd is priced at.
