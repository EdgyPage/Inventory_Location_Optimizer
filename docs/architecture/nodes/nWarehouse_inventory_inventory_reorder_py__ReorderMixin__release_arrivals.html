function _release_arrivals

layer wh_inventory · file Warehouse/inventory/inventory_reorder.py

def _release_arrivals(self) -> list
Release arrived orders (remaining_lead ≤ 0) into the stock queue. Catches both decremented-to-0 olds AND fresh lead-0 newcomers in the same batch, which is why it runs after `_fire_reorders` rather than before. Returns this batch's `LoadPlan`s -- what came off the trucks, in arrival order. The phase is a producer with no consumer today; the return exists so a receiving crew is a caller of an existing phase rather than a rewrite of one.
