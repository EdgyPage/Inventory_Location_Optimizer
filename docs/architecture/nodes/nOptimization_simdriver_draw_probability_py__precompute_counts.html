def precompute_counts(inv_db, max_skus, sku_allowlist, aff_db, batch_cfg, seed_batches: int, n_draws: int, workers: int=1, chunks: int=_DEFAULT_CHUNKS, channel_regime=None) -> tuple
Draw `n_draws` batches and return `(bounds, counts)`. `bounds` is the list of `(lo, hi)` chunk ranges in order and `counts` the matching `(len(bounds), n_skus)` int64 matrix, so `counts[:j].sum(0)` is the count vector at prefix `bounds[j-1][1]` -- the ladder, from one draw.
