def _wp_for(wp, obj)
Resolve the WorkloadParams for *obj*'s storage regime from a mixed-warehouse ``wp.by_regime`` map, falling back to *wp* itself. Placement/assignment sites process one regime at a time (a BinKey group / a single unit), so resolving from that entity is exact; single-regime runs carry no map and return *wp* unchanged (store byte-identical).
