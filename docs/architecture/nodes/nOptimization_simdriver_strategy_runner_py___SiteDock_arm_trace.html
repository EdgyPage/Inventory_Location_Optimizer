def arm_trace(self, path: str, every: int) -> None
Record every `every`-th batch's gain plans into `path` (the contract's `site_plan_trace`). The file is TRUNCATED here: a coupled unit always replays from batch 0 (`_plan_strategy_start` refuses a batch-level resume), so a retried unit rewrites its trace rather than appending a second copy of the early batches.
