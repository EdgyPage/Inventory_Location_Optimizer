def merged_effect_panel(keys, colors, box_values, tests, out_path, *, title, lower_is_better, conv=None, unit_label='', max_ladder=28)
One metric, one figure: distribution (left) + pairwise effect ladder (right). `box_values` are RAW per-block samples per key; `conv` maps them into presentation units for the left panel only (effects are unitless). `tests` is a stats_core._run_tests document over the same keys. With more pairs than `max_ladder` (a 17-arm family gives 136), the ladder keeps only baseline-vs-each — every pairwise number still lives in the tests JSON beside this figure. Returns the saved path, or None when there is nothing to draw.
