backbone
def _run_whatif_matrix(base_dir, pairs, log, spec, resume=False, max_retries=2, resume_granularity='strategy')
Drive a cell-matrix run from a spec (see whatif_config.SPECS): every run is a matrix, so a plain run is the single cell ``k1_off``. A MULTI-cell matrix freezes the sampled inventory once (tightest cell) and reshapes it per cell (apples-to-apples); a SINGLE-cell run skips the freeze and samples fresh — bit-identical to the old flat run, just nested under its cell dir. Returns {'cells': [names], 'reference': name}.
