function _refuse_unfillable_cells

layer opt_config · file Optimization/config/whatif_config.py

def _refuse_unfillable_cells(spec, name: str) -> None
Refuse a FILL TRIAL spec whose cells the fill would refuse one at a time. `sim_config.fill_spec` refuses an inbound-off cell (no trailers: nothing would land) and a trailer-bound cell -- but only when that cell is PREPARED, which under the flat work pool can be hours into a matrix. The same two facts are readable off the spec, so they are refused here, before anything runs (inbound-throughput Q23), together with the regime a fill needs at all: the coupled era.
