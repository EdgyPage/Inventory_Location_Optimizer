def take(self, unit)
(bin, score) for one unit; (None, None) when no aisle has a bin left. `score` is the compaction objective in seconds -- `x_pace * |x(bin) - cx|`, the distance from the partners' demand-weighted column centroid that the bin choice minimises (compact) or maximises (expand). None before this SKU has any partner placed, because there is then no centroid and the bin was taken by the cold-start rule instead. The AISLE was chosen on lift, which is a different quantity and not a property of the bin.
