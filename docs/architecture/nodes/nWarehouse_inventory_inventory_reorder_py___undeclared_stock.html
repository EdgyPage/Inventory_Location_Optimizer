function _undeclared_stock

layer wh_inventory · file Warehouse/inventory/inventory_reorder.py

def _undeclared_stock(order) -> NoReturn
Raise `UndeclaredStock` for an order no run has declared a stock level on. The `inventory_common._equilibrium_qty` precedent, at the other end of the same declaration and for the same reason. A RAISER rather than a `_reorder_point(order)` accessor on purpose: `_notify_pick` is the pick loop's O(1) hook -- once per pick mutation, hundreds of thousands of times a batch -- and both call sites already had the `is None` test they need. Written this way the guard costs the fast path nothing at all, so no future profile can argue it back out of existence.
