class PutawayPool
The site's putters: one clock list, one uid block, one carry, N leaves. Constructed by the driver at UNIT scope, where the crew is sized from the staffing record, and bound onto each leaf it serves (`mgr.putaway_pool`) — the same injection precedent as `enable_receiving`, `mgr.packer` and `mgr.receiving`: the broker holds what it is handed, and nothing under `Warehouse/` imports this package. `clocks` and `workers` are parallel and index-aligned: clock `w` is worker `w`, which is what lets `work_events.put_rows` name the same person in both channels' DBs. The driver mints both, exactly as it mints every other crew — this holds them.
