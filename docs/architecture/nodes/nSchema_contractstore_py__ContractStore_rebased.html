def rebased(self, tree_dir: str) -> 'ContractStore'
The same store, pointed at a different directory. THE SEAM FOR A THROWAWAY STORE. Redirection used to be done by monkeypatching two module globals (`_TREE_DIR`, `_INDEX`), which worked only while every operation re-read them -- and silently stopped working the moment they were read once at construction. A test that patches a global the code no longer consults does not fail; it runs against the REAL committed store, which for a test that calls `adopt` is the worst possible outcome. So the redirection is an operation rather than a convention, and it carries `shape_of` and `diff` with it: a throwaway store that hashed a different projection would prove nothing about this one.
