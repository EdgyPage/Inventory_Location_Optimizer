def unload_cost(weight: float, volume: float, quantity: int, cost: UnloadCost) -> float
Seconds to take ONE storage unit off a trailer. `weight` and `volume` are PER ITEM — `order.weight` and `order.volume()`, exactly as `put_cost` takes them. Passing a pack's or a trailer's volume instead inflates the log term by `ln(quantity)` per unit, and `handle_var` clamps its log input to >= 1 so it never raises: a 34-pallet arrival would simply cost as if every item were 34x bigger. `quantity` is the merchandise in THIS pack (`unit.quantity`), so the intercept is charged once for the pack and the variable term once per item in it. Returns SECONDS, the unit the whole simulator counts in (`Warehouse.kernel.timeline.TIME_UNIT`).
