def _assert_json1() -> None
The viewer's scoped named queries pass id lists as ONE JSON parameter via json_each. JSON1 has been compiled into the bundled SQLite by default since 3.38 (Python 3.11 ships newer), so this probe should never fire — but a viewer that silently lacked it would fail on the first scoped request with an opaque OperationalError mid-session. Probe ONCE at import and fail with the cause named.
