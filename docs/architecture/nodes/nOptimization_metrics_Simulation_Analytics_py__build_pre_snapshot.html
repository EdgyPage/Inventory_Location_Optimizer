def build_pre_snapshot(manager) -> dict
Capture bin quantities before a batch simulation runs. Call immediately after check_reorders() and before DeferredPickSimulation: the instant it describes is "start of this batch, after the restock pass, before any pick". Returns a dict keyed by id(bin). Two consumers, both live: - the keyframe writer (`save_bin_keyframe`) — the independent audit of the log; - the per-batch conservation ledger in `strategy_runner`, which sums `pre_qty`. Its third consumer, `snapshot_bin_inventory`, is GONE — `bin_inventory` was pure redundancy once `bin_placement` + `bin_eviction` + `picks` existed, and is no longer written. Only non-empty bins are captured; empty bins are implicitly quantity=0 and are not written.
