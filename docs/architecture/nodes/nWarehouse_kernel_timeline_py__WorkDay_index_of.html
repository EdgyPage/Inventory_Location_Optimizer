def index_of(self, t_abs: float) -> int
Which day the absolute instant falls in, 0-based from `origin`. An instant BEFORE the origin belongs to a negative day rather than to day 0. Day 0 is a real interval, and folding everything earlier into it would make the first day look longer than the rest.
