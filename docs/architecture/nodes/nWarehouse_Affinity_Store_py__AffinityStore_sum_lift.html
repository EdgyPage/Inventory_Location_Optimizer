def sum_lift(self, skus: list[int]) -> float
Total association ABOVE independence within skus: Σ (lift − 1) over all stored ordered pairs. Extracts a (k × k) submatrix and sums it in C, then subtracts the stored-entry count (each stored pair contributes lift − 1; independence pairs contribute 0). Both (i,j) and (j,i) are stored, so each undirected pair is counted twice — consistent with the ordered-pair convention used throughout.
