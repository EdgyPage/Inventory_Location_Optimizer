@dataclass
class WorkloadParams
Coefficients that define how physical effort is estimated for one aisle. Mirrors the relevant fields of PickConfig (Warehouse/Pick.py) so the Optimization layer can compute W without importing simulation internals. Fields ------ x_speed : horizontal travel speed in ft/s (positions are inches) y_speed : vertical travel speed in ft/s (positions are inches) pick_intercept : fixed overhead per P stop pick_weight_coef : time added per (weight × quantity) unit pick_volume_coef : time added per (volume × quantity) unit cart_swap_coef : penalty per additional cart needed beyond the first
