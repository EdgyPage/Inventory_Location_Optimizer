def delta_lift_sorted(self, sku: int, sorted_member_arr: 'np.ndarray') -> float
Sum of lift between sku and members described by a sorted numpy array. Faster than delta_lift_idxs for large member sets: uses np.searchsorted on two pre-sorted arrays (CSR indices are sorted within each row by the scipy CSR format; sorted_member_arr is maintained by the caller). Zero per-call allocation when sorted_member_arr is cached.
