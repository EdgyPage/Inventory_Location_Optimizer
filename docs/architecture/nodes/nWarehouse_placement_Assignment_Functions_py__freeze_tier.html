cross-layer
def freeze_tier(cands, wp) -> FrozenTier
One tier's candidates sorted ONCE, under the paces and brackets the pools resolve from `wp` -- the gain evaluator's per-drain freeze (`Inbound/gain.py:_tier_for`). Built HERE, beside the pools that read it, because `Inbound` may not import the placement engine: the driver hands the evaluator this function through the bundle (`GainBundle.freeze_tier`), the same way `wp_of` and `binkey_of` cross that seam. A pool handed the result checks that its own paces and brackets are the ones the tier was frozen under (`_check_tier`), so a mixed warehouse's per-regime `wp` cannot be served another regime's geometry.
