class _CowFloats
Copy-on-write over `{aisle: float}` -- and floats need NO copy at all. A float is immutable, so a read can fall straight through to the live dict; only a write needs an overlay. `_ads[aid] += fq` is `__getitem__` then `__setitem__`, and the write lands here rather than on the manager's dict. `__getitem__` on a miss CREATES the entry at 0.0, matching `defaultdict(float)` -- the shape this replaces -- so `len()` and iteration order are unchanged.
