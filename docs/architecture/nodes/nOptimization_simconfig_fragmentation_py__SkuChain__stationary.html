def _stationary(self, PT, n: int) -> np.ndarray
`pi = pi P` by power iteration on the LAZY chain `(P + I) / 2` from the fielded state -- the same stationary law, and aperiodic whatever cycle the drain runs in. The chain regenerates whenever a line empties the shelf, so the reachable set holds one recurrent class and the iterate converges geometrically; it stops when the L1 step is below `POWER_TOL`. A chain still moving at `POWER_SWITCH` steps is a slow mixer and goes to the pinned direct solve (`_direct`); `solver` records which path answered, `iterations` how many steps it took. A direct solve with a normalisation ROW was tried first and dropped: the dense row fills the LU factors in, and a 9,000-state class cost four seconds against a twentieth of that by iteration; the pinned form keeps the system sparse.
