def _stock_ranked(self) -> None
Ranked placement: sort units by pick-effort priority, then drain. Groups the queue by BinKey (handling, category, storage_size, unit_type) — the same key used by _candidates() — so units only compete with others in the same bin pool. Within each group, placement.place_wave returns (unit, bin|None) pairs sorted by pick-effort priority so high-effort items claim the best (lowest-D) bins before lower-priority items. Units the wave cannot place are handed to the per-unit path (_stock_per_unit), which re-fetches candidates per unit so they spill into other tiers / remaining bins exactly as FIFO does (see below).
