def capabilities(self) -> frozenset[str]
Which optional data this arm actually HAS — probed for ROWS, then memoised. A present-but-empty table is the common case, not an edge case: `aisle_metrics` and `reorder_queue` are only written by strategies that maintain that state, and are empty for every arm of the current production run. Reporting them as absent is what lets the UI hide a panel instead of rendering 0.0 as though it were a measurement.
