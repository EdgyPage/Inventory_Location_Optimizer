def reorder_formula(*args)
This run's realised inventory averages — deliberately NOT a closed form. It used to print one, and the formula it printed did not reproduce the catalogue: the planner's equilibrium target is rescaled to fit the warehouse afterwards, so the stated form was out by an order of magnitude, and neither candidate reorder-point expression matched more than about half the stored values. A macro that prints an equation asserts the equation holds. This prints the averages the run recorded; `inventory_model()` publishes the distribution behind them.
