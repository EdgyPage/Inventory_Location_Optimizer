def read_only(path: str, *, row_factory: bool=True, immutable: bool=False)
Open a finished artifact strictly for reading. Never use a writer here: `PRAGMA journal_mode=WAL` is a WRITE, so it fails on a read-only mount and otherwise leaves sidecar files next to an archived database. `immutable=True` additionally promises the file will not change while open, which lets SQLite skip locking entirely — correct for an archived run, wrong for one still being written.
