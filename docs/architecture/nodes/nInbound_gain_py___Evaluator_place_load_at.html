def place_load_at(self, units, start, predicted: bool)
`place_load` for a MERGE-ONLY load against a frontier instead of an exclusion set: `start(key)` is the offset into each tier's sorted array below which every bin is excluded. Returns `(cost, takes, counts)`, `counts` being `{tier: bins taken}` on the now side (None when `predicted`, whose tails are merged views and whose takes nobody commits). The grouping, the owner cursor, the unit order and the pricing are `place_load`'s own -- the same loop, the same `_place_merge` -- so the floats are summed in the same order and come out bit-identical. Only the availability read differs.
