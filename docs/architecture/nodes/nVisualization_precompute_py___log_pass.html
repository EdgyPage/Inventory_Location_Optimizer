layer visualization · file Visualization/precompute.py

def _log_pass(sim_con, run_id, batches, bin_picks)
One ordered scan each of `bin_placement` + `bin_eviction` -> spans exact at EVERY batch. Returns `(spans, homes, final_batch, deltas)`. `deltas` holds per-`(aisle, batch)` STEPS for the four rollup metrics rather than their values: a span contributes `+1` at `t_from` and `-1` at `t_to + 1`, so the rollup prefix-sums in O(spans + picks) instead of expanding bins x batches — 2.2M steps against 39.65M cells on a production arm.
