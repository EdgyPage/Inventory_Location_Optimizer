def release(self, now_s: float | None=None) -> list[list]
Pop and return every arrived entry (remaining_lead <= 0), in queue order. Un-arrived entries keep their order; a negative remainder is an order that arrived while nothing drained it — never clamped, because clamping would hide the backlog.
