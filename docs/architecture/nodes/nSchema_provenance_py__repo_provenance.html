{'repo_commit': <short sha> | 'unknown', 'repo_dirty': True | False | None}. `repo_dirty` is deliberately THREE-valued: True/False are answers, `None` means "not established" — which is what an export or a missing git binary honestly is, and reading it as "clean" would be the one wrong inference.
