def metric_specs() -> list
`stats_core._METRICS` — (name, source_kind, column, lower_is_better). Filtered to `PAIRED_KINDS`: the significance suite pairs batch i of one arm against batch i of another, and a per-trailer or per-drain frame has no such pairing to offer. A kind that is in neither list raises rather than being dropped, because "silently absent from every published CSV" is the exact failure mode this table was built to end.
