def _template_regex(declared: str) -> re.Pattern
Compile a declared path template into a matcher for OBSERVED templates. Observed templates carry placeholders as literal text (`{cell}`), so those compare exactly; only the glob forms are fuzzy: `**/` spans any number of segments, `*` stays within one.
