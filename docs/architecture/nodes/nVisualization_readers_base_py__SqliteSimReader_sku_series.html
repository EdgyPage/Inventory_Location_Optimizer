def sku_series(self, skus: list[int]) -> dict
Per-batch pick counts for the given SKUs. Indexed by `(run_id, sku)`, so cheap live. The sidecar's `sku_series` holds only the top-N window, so a mixed request is a PARTIAL hit: taking it as complete would report every SKU outside the window as never picked — the exact failure `sku_rank` exists to prevent. So the cache is used for what it has and the remainder falls through to the live query, which is index-served and cheap.
