def strategies_for(restocks) -> list[Strategy]
Subset of STRATEGIES whose restock rule is in `restocks` (None ⇒ all). Lets one channel run only a subset of restock rules (e.g. store: fifo + rank_labor) while another runs the full suite, without perturbing the global grid used elsewhere.
