def _git_dir(repo_root: str) -> str | None
The `.git` directory for `repo_root`, or None when there is no git metadata at all. `.git` is a DIRECTORY in a normal clone and a FILE holding `gitdir: <path>` in a linked worktree or a submodule, which is why this is not a bare isdir() check.
