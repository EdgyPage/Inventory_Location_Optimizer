def _futuresight_window(text: str)
An argparse `type=` for the futuresight window: `'all'` or a non-negative int. The knob is a batch COUNT with a string sentinel for the oracle, and `_futuresight_batches` (the spec-build normalizer) rejects `'5'` as firmly as it rejects `'oracle'` — its `w != raw` test is what stops a fractional value, and a numeric STRING fails it too. So the conversion has to happen at the parser: without it, `--inbound-futuresight-batches 5` would parse cleanly and then refuse at spec build, naming the settings constant rather than the flag the user actually typed.
