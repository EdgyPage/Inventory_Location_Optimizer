def validate_spec(spec, name: str='<spec>') -> None
Refuse a cell-matrix spec whose SHAPE cannot mean what it says. Raises ValueError. Called from `get_spec`, which is the single door every run comes through — so this fires before the run directory exists, before the catalogue is read and before a worker is forked. Cheap, total, and pure: it reads the spec and the rule grid, nothing else.
