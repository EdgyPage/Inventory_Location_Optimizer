def validate_spec(spec, name: str='<spec>') -> None
Refuse a cell-matrix spec that cannot mean, or cannot DO, what it says. ValueError. Called from `get_spec`, which is the single door every run comes through — so this fires before the run directory exists, before the catalogue is read and before a worker is forked. Cheap, total, and pure: it reads the spec against declared registries and nothing else — the rule grid, and (since inbound-optimization 33) the two that say what a named policy and a named rule can actually be run with, never the simulation. The shape refusals come first and `_refuse_unrunnable_cells` last; both kinds guard the same thing, a run that completes, publishes, and measures something nobody chose — or, for the last one, one that pays its freeze and then dies at its first drain.
