def render(template: str, **parts) -> str
Render a contract path template to a relative path. `{name}` substitutes parts[name]; `{name?}` is an OPTIONAL segment that is dropped along with its separator when parts.get(name) is None. Raises KeyError for a missing required part, so a typo fails loudly instead of producing a path with a literal brace in it.
