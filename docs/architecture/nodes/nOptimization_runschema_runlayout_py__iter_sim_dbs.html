def iter_sim_dbs(base_dir: str) -> Iterator[tuple[ChannelRun, str]]
Yield (ChannelRun, sim_db_path) for every per-strategy result DB under base_dir. Structural walk over <pair>/<config>[/<channel>]/sim_<strategy>.db — keyframe DBs excluded. Channel subdirs are found even when sim_meta.json was never finalized (crashed runs), so blank-arm scans see everything.
