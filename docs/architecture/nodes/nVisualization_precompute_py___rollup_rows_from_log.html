def _rollup_rows_from_log(run, batches, capacity, deltas, aisle_picks, task_secs)
Per (batch, aisle) rollups, prefix-summed from `_log_pass`'s per-batch steps. Exact at EVERY batch — nothing inherits a keyframe any more. The running totals are carried across the full batch range rather than across `batches`, because a batch that produced no tasks writes no `batch_stats` row (`RECONSTRUCTION.md` §7) and skipping its steps would desynchronise every batch after it.
