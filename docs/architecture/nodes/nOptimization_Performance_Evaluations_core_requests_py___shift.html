Every arm's per-day ledger frame -- `{key: shift_df}`. ERA-UNMET, not Denied, when no arm closed a single day: the files were read and hold no drain-or-cap ledger, which is every run before the calibrated era and every flag-off run since. A throughput audit over that would report "every day drained" about a site that never had a day. The `days_capped` quantity names the `shift_days` capability, so the probe refuses the audit before this compose runs; this check is the same fact found the other way round, for a caller that declared no quantity.
