Optimization.Performance_Evaluations.comparison.top_vs_baseline
compare.top_vs_baseline — how the best runs compare to the FIFO/random baseline. Two stakeholder-facing artifacts under compare/: * top_vs_baseline.png — grouped bars, % improvement of each top run vs the FIFO baseline across the headline metrics (higher = better). * top_vs_baseline_table.png — a supporting table graphic (for the site): one row per top run with its assignment function, the % difference in TOTAL task time vs FIFO, and the statistical significance (paired Wilcoxon p over all batches). Baseline = strategies[0] (the FIFO/uniform-random run). Params: top_n, top_by.
