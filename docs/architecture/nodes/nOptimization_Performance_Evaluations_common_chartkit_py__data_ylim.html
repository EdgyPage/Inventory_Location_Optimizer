def data_ylim(ax, values, *, pad=0.08, include=())
Clip y to the data range (+pad fraction) instead of anchoring at zero. When the resulting window excludes zero the axis is visibly TRUNCATED: a marker glyph on the y-axis spine plus a small corner note, so nobody mistakes a zoomed axis for the full range.
