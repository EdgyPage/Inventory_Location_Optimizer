@dataclass(frozen=True)
class PutawayCost
The put-away time model's coefficients — the put-side twin of `PickConfig`'s. Defaults mirror `PickConfig`'s own dataclass defaults, so a caller that supplies nothing gets the pick model's shape at the pick model's scale rather than a second set of magic numbers to reconcile later (this project has already paid for two default sets that drifted 55x apart).
