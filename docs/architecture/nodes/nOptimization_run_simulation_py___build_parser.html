layer optimization · file Optimization/run_simulation.py

def _build_parser() -> argparse.ArgumentParser
Every flag `run_simulation` accepts, and nothing else. Split out of `main`, which was 875 lines holding four unrelated things: this parser, the CONFIG override loop, the two contract prechecks, and the run. Only the last three have anything to do with each other. DEFAULTS COME FROM `CONFIG`, NEVER FROM A LITERAL. That is the invariant the whole five-seam chain rests on -- a flag whose default were written out here would disagree with `settings.py` the moment the setting moved, and the run would be shaped by whichever of the two the reader happened to trust. `Tests/unit/test_cli_surface.py` checks the pairs against the live CONFIG rather than against this file's text. Reads CONFIG; never writes it. A parser can therefore be built by a test without reshaping the run that follows.
