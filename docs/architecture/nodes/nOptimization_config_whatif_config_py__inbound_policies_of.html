layer opt_config · file Optimization/config/whatif_config.py

def inbound_policies_of(spec) -> tuple[str, ...]
Every yard/dock policy the spec NAMES, distinct and in declaration order — from its inbound axis and its run defaults alike. Two key spellings, because the two seams have two: an inbound axis entry states `yard_policy` (a `CONFIG['global']` `inbound_*` name with the prefix dropped, which is what `_inbound_axis` validates against), while `run_defaults` states the full `inbound_yard_policy`. A gate that read only one of them would pass a spec that names its policy at the other seam.
