@env.macro
def unload_ranking(pair=None, control=False)
The unloading-policy ranking of a phase-2 experiment, from the committed ranking artifact under `data/` — one row per cell, in rank order, for one rule pair. `pair` is the rule-pair label (`store_rule/ful_rule`); the artifact's primary pair by default, its rider (the control) with `control=True`. Numbers live in the JSON, so the page holds only prose; the caption names the floor that applied and how it was obtained, because a rank inside a tie group is the tie-break's, not the score's.
