def packing(plan: tuple, r: int) -> tuple[Kind, ...]
The units a lot of `r` items packs into: the plan's LEADING slots filled in order, `take = min(per, remaining)` per unit -- `viable_storage_units`' plan branch, for a lot at or below the plan's total (a lot never exceeds the order-up-to). Returns the kinds `(single, n0)` in packing order; `r <= 0` packs nothing.
