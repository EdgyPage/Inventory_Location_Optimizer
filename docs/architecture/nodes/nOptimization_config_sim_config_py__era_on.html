Whether this run is under the calibrated era: the drain-or-cap shift is on. ONE predicate for "derive the crews, refuse the legacy crew flags, price the script from the calibration record", read from CONFIG at call time. The same key `work_day_spec()` carries to the worker as `drain_or_cap`, so the parent and the worker cannot disagree about which regime a run is in.
