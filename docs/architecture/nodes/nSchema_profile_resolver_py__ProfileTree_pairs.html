layer schema · file Schema/profile_resolver.py

def pairs(self, profile_run: str) -> list
(label, inventory_db, affinity_db) for every complete profile in one run. Descriptor-first: profiles listed in `profile_layout.json`, resolved through the contract templates, existence-checked (a descriptor is a claim; the DB is the fact). Fallback: the byte-for-byte mirror of `runlayout._profile_pairs` — sorted listdir, literal `inventory/inventory.db` + `affinity/affinity.db`, both-exist filter. The label is ALWAYS `f'{profile_run}__{profile}'` — the run tree's pair level.
