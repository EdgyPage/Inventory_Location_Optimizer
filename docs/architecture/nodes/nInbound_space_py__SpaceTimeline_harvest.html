def harvest(self, bins, stamps) -> None
The reclaim-harvest: called by `_reclaim_empty_bins` with `_pending_reclaim` and `_emptied_at` at the one moment they meet before both are wiped. Every reclaimed bin bumps `reclaim_v` (the index changed for each); only bins with an actual stamp enter `emptied_at` (a stampless notification — a caller with no clock — frees the bin without asserting when).
