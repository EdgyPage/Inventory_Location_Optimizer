class AisleLedger
The aisle ledger: ten dicts, one owner, one add/drop pair at each grain. The dicts are exposed as plain attributes, not properties. They are read on the placement hot path by closures that hoist them once outside their loop, and an indirection there is a per-candidate cost — the same argument `inventory_zoning` records for staying a mixin.
