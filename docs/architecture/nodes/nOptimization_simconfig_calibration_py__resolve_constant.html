def resolve_constant(entry: dict, *, override: float | None, analytic: float, name: str) -> dict
One constant, resolved by the rule in the module docstring. Returns `{value, provenance, source, ...}` where `source` says which branch fired (`override` / `record` / `analytic`), so a reader of the staffing record can tell a typed number from a copied one from a computed one without inferring it from the provenance alone. A seed with no analytic to scale (an absent channel, or a catalogue whose section is empty) resolves to 0.0 and is flagged `unpriced`.
