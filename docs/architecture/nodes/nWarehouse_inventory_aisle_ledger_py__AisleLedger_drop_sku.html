def drop_sku(self, aid: int, sku: int, idx: int | None, *, last_when_zero: bool=False) -> bool
Decrement the SKU's bin count; on its LAST bin, retire it and subtract its levels. Returns True when the SKU left the aisle. Every subtraction is clamped at zero, as the two hand-written copies were. `last_when_zero` reproduces the difference between the two original copies: the cold path used `elif n == 1`, so a defensive n == 0 fell through and did nothing; the hot twin used a bare `else`, treating n == 0 like n == 1. The twin's callers pass True.
