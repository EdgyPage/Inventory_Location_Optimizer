function _positive_float

layer optimization · file Optimization/run_simulation.py

def _positive_float(text: str) -> float
An argparse `type=` for a DURATION that is meaningless at zero. `--recv-day-seconds 0` would mean "the crew has a day of no length", which is not the same as "the crew has no whistle" (that is omitting the flag) and is not a configuration anyone wants. Rejected at the parser for the same reason `--n-batches 0` is: argparse prints the flag name and exits 2, instead of the value being quietly turned into its opposite by an `or`.
