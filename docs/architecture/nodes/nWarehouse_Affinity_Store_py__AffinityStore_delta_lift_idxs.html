def delta_lift_idxs(self, sku: int, member_idx_set: set[int]) -> float
Association ABOVE independence: Σ (lift − 1) between sku and a pre-translated set of matrix indices. Index-set form of delta_lift() (no per-call {_sku_to_idx[s] ...} comprehension). Lift = 1 is independence ⇒ each stored partner contributes (lift − 1); unstored pairs contribute 0. The caller keeps member_idx_set current with the aisle's SKU composition (add on placement, discard on removal).
