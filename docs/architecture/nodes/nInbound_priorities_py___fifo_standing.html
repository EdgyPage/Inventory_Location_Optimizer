def _fifo_standing(trailer, ctx) -> float
Longest-STANDING first: earliest yard arrival wins. The charter's order — arrival stamp, `seq` as tiebreak — needs only the stamp here: both standing collections (the yard, the staged set) are maintained in (stamp, seq) order, and `bounded_order`'s sort is stable, so equal stamps fall back to `seq` for free. A trailer with no stamp (no clock reached the drain — bare test managers) ranks oldest rather than crashing or silently sorting last: it has been standing since before anything the clock can see.
