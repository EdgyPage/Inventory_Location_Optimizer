def write(self, doc: dict) -> str
Write a document to its versioned path, atomically. Returns the path. Two refusals rather than a silent overwrite: a document whose stated id is not its own hash is not content-addressed at all, and a SHORT-PREFIX COLLISION would put a different schema under this filename -- astronomically unlikely at 48 bits and unrecoverable if it ever happened.
