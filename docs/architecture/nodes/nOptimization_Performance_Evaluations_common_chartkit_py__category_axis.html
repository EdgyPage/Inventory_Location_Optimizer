def category_axis(ax, labels, *, orient='h', fontsize=7, pad=0.8)
Tick, label and bound one axis of categories, so N categories always look alike. `orient='h'` lays the categories down the y axis (horizontal bars/dots, first at the TOP); 'v' lays them along x. Returns the positions, which is what the caller plots against. Eight modules did this by hand with four different tick fontsizes and four different limit paddings, so the same 34 arms occupied visibly different amounts of chart from one family to the next.
