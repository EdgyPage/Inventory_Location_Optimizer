def _leaf_file(rt, cell, inv, cfg, name, cfg_src)
One curated file at a (cell, inventory, config) leaf, or None if absent. With a resolver, `config.json` is the contract's `config_json` artifact, and a figure is looked up inside the CONTRACT-RESOLVED channel-run leaf (`rt.channel_runs`) — the resolver consumes the `<channel>` level, so this function never has to guess whether one exists. Within a leaf the pick is by the EXPLICIT dir preference above (which analysis subtree owns a duplicated basename is now data, not walk order); `_find` remains for figures outside that vocabulary, and — without a resolver (pre-descriptor run, `--source` at a single cell dir) or for a leaf not yet finalized — over the config dir, the unchanged legacy route.
