def time_units(values) -> tuple[float, str]
(divisor, unit_label) — the largest time unit keeping typical magnitudes >= 1. Chosen from the pooled MEDIAN absolute magnitude so one outlier cannot drag the whole axis into a smaller unit. Deterministic, so the same quantity picks the same unit on every re-render; the unit always appears in the axis label, so no chart can be read in the wrong one. Falls back to seconds on empty/degenerate input.
