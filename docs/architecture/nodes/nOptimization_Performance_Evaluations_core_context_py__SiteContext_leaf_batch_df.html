ONE leaf's batch frame inside a site — the per-channel SHARE, never the site's. Printed BESIDE the site number and never instead of it (memory `a-right-site-total-hides-two-wrong-shares`: put-away's site load was 0.9% exact while both per-channel bands failed in opposite directions). Not memoised: it is read once per arm pair per render, and a second cache keyed by `(key, channel)` beside the shared frame cache is a second thing to invalidate.
