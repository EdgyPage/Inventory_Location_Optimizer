def cost_rows(ctx) -> list
One row per (channel, rule), with both spans and both normalisations. Grouped by CHANNEL, not by leaf: a rule's compute cost is a property of the rule and the catalogue it scores against, and the two channels have genuinely different catalogues. Cells and pairs collapse into the median, which is what makes `n_arms` worth printing beside it.
