layer inbound · file Inbound/transit.py

def _load(self, sku: int, qty: int, unit_volume: int | None, now_s: float | None) -> None
Load one order, item-by-item, FIFO next-fit across trailers. The trailer's lead is drawn HERE, at creation, and never again: it is a property of the trailer from the instant it exists, so `dispatched_s + lead_s` is a fixed arrival the yard can be sorted by however many drains later it is observed. `dispatched_s` is the epoch of the drain the order LOADED in — after its supplier lead, not the drain it fired in.
