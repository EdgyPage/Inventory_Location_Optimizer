def _focus_filter(strategies, focus)
Restrict strategies to one initial family by key prefix ('uni'/'opt'); fall back to all if the prefix matches nothing or focus='all'. opt_* win mainly from their initial-stock advantage, so 'uni' isolates the reorder-policy comparison.
