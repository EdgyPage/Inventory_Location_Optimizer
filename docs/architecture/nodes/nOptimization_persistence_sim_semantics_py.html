Optimization.persistence.sim_semantics
sim_semantics — the sim_db (and keyframes) column semantics, declared beside their DDL. The structured form of every warning `Picking_Data.py`'s DDL comments carry in prose: kind, unit, unit of account, grain, clock, null-meaning and the scar that earned each tag. Keyed exactly as `SIM_DB_FAMILY.declared_shape()['tables']` keys its columns, so the completeness gate (`Tests/architecture/test_column_semantics.py`) is a dict diff with nothing to drift. Every table of both families is COVERED — the convention pass left no remainder. Tags are metadata: importing this module changes no DDL, no shape id, no result.
