def resolve_constants(rec: dict, *, overrides: dict, analytic_pick: dict, analytic_put: float) -> dict
Every constant the derivation needs, resolved against `rec`. `overrides` is `{'s_pick_store', 's_pick_ff', 's_put'}` (None = no override -- the three CALIBRATION_KEYS of the staffing inputs); `analytic_pick` maps a channel name to its stage-A `seconds_per_unit` (absent channels omitted); `analytic_put` is the site's analytic put seconds per unit (from the script, stage B) -- zero when the seed has to be resolved before stage B, in which case the caller re-resolves `s_put` once it has it. Returns `{'s_pick': {channel: constant}, 's_put': constant, 'k_max': {channel: int|None}, 'record': <provenance stub>}`.
