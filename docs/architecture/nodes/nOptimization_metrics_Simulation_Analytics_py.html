Optimization.metrics.Simulation_Analytics
Simulation_Analytics.py — per-batch and per-task statistics from PickSimulation events. Public API ---------- avg_concurrent_pickers(events) Time-weighted average number of pickers simultaneously in "picking" state. Aggregate picking vs traveling fractions across all pickers. extract_batch_stats(events, batch_id, k_pickers, run_id) Summarise one PickSimulation run into a BatchStats record. extract_task_stats(events, tasks, batch_id, affinity, wp, run_id) Extract per-aisle TaskStats from one PickSimulation run. flag_batch_outliers(stats, iqr_factor) IQR outlier detection on batch duration. flag_task_outliers(stats, iqr_factor) IQR outlier detection on task duration. build_placed_affinity(warehouse, inventory, max_per_group) Sparse lift matrix for only the SKUs that have a physical bin. sum_lift(skus, affinity) Demand-weighted co-occurrence helper for a dict-based lift matrix (AffinityStore objects carry their own faster .sum_lift; this is the dict fallback).
