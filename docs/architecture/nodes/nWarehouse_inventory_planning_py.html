Warehouse.inventory_planning
inventory_planning.py — warehouse sizing/sampling (pre-instantiation). `PlanningMixin` holds the static/class methods that size a warehouse FROM an inventory before any manager instance or warehouse exists. Mixed into Inventory_Manager so the public API (`Inventory_Manager.plan_warehouse(...)`, `.bucket_requirements(...)`, `.sample_to_capacity(...)`) is unchanged.
