Warehouse.inventory.inventory_reorder
inventory_reorder.py — churn counters, reload primitive, pick notifications, and Order-Up-To reorder logic. `ReorderMixin` holds the per-batch lifecycle methods. Mixed into Inventory_Manager so the public API (`pop_churn`, `requeue_bin`, `check_reorders`, and the O(1) pick notifications called by PickSimulation) is unchanged. All instance state and the collaborators it calls (`self._index_add`, `self._stock`) are provided by Inventory_Manager.__init__ / its placement methods.
