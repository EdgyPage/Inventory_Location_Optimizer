def read_layout(warehouse_db: str) -> tuple[list[dict], dict[int, int]]
Aisle geometry + per-aisle bin capacity from a run's `warehouse.db`. HARD FAIL on an unvetted shape (`identity.check` raises `UnsupportedSchema`), unlike the viewer, which warns. Capacity is the DENOMINATOR of every fill percentage this tool exports, and the dashboard renders those percentages as a measurement. A geometry table that is not the one we think it is produces a fill curve that is wrong in a way no reader can see — the same class of defect as the `bin_inventory` decay documented in `_SOURCES`, which is why that entry exists at all. Better to name the differing column and stop. Both archived shapes are vetted (`Warehouse_Data.PRE_STAMP_WAREHOUSE_SCHEMA_ID` and `PRE_FINGERPRINT_WAREHOUSE_SCHEMA_ID`), so this refuses nothing that exists today.
