def _coverage_record(pair: str) -> dict | None
The coverage block this run recorded for `pair`, or None when it recorded none. A rebuild re-declares the run's stock levels from it before planning: the catalogue carries none (ADR-0002) and the warehouse is sized from levels, so without this a re-analysis would size from nothing. None is the honest answer for a run written before the record existed, and `build_shared_assets` refuses rather than fabricating.
