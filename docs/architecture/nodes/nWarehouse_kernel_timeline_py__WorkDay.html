class WorkDay
A fixed-length working day on the absolute axis. `length` seconds long, starting at `origin`. Days are back to back: there is no gap between the end of one and the start of the next, because a gap would need a calendar and this model has none. Overnight is expressed by making the day shorter, not by inserting emptiness between days. Pure arithmetic. Nothing here reads or advances a clock -- a caller passes an instant in and gets an instant back, which is what makes it testable without a simulation.
