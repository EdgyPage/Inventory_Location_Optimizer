class Dataset
One bound file: reads validated against the file's OWN shape, queries served by vintage. Not a context manager by accident — it IS one (`with dataset.bind(...) as ds:`), and `.con` stays public as the documented escape hatch for hand-written aggregate SQL (whose reads must still appear in the consumer's `Requires`, where CI can see them).
