def _script_j(i: int)
Batch `i`'s index into the pick SCRIPT -- `i` itself on every run but a fill trial's, whose pick stage starts at `script_off`; None on a FILL day, which has no demand at all. `i - 0` is `i`, so the ordinary run reads the script exactly as it always did.
