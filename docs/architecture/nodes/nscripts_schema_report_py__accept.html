def accept(out=print) -> int
`adopt --apply` then `sync`: the one-command close of a DDL change. Order is load-bearing: `--apply` EDITS a DDL source file, so the fingerprint must be recorded AFTER it (a sync-first ordering would record a fingerprint the apply immediately staled). Exit is `adopt`'s exit - 1 means something was adopted and the TODO comments now need filling.
