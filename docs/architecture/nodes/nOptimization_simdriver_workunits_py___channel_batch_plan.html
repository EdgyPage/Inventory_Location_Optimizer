def _channel_batch_plan(ch, inventory, mixed: bool, shared: dict) -> tuple
(batch_cfg, seed_batches, channel_regime) for one channel-run's batch stream. Mixed catalogue: the channel's own BatchConfig over its regime's SKU count, its own seed offset, its regime as the precompute filter. Store-only: the pair-level shared BatchConfig (= the store channel's shape), the base seed, no filter -- byte-identical to the pre-channel pipeline. ONE helper for the same reason as `_worker_inventory_args`: two callers computing the plan is two fingerprints.
