layer wh_catalog · file Warehouse/catalog/Affinity_Store.py

def _init_schema(self) -> None
Create the tables ONLY when something is actually missing. This used to run unconditionally, which meant opening a complete, generator-written `affinity.db` — even purely to read it — silently ADDED `sku_group` and changed the file's shape. A database whose structure depends on whether it has been opened yet cannot be fingerprinted, and the mutation also drifted it away from what `context/artifacts.yml` declares. The generator now declares `sku_group` too, so the common path finds everything present and touches nothing.
