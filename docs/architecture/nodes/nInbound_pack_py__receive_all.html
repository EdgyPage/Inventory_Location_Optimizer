function receive_all

layer inbound · file Inbound/pack.py

def receive_all(order, deliveries) -> list
Pack a shipment that arrives as several deliveries. `deliveries` is a list of quantities -- how the shipment was split, and nothing about WHY. Trailers, docks and load planning are the caller's business; this seam exists so they can be written without touching the packer. Every returned plan carries the shipment total, so `split_penalty()` is answerable on each and meaningful when summed.
