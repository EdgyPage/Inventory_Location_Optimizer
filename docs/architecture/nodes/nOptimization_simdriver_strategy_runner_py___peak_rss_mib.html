def _peak_rss_mib() -> float | None
This process's peak working-set (high-water RSS) in MiB, or None if unreadable. Stdlib-only by design — psutil is deliberately not a production dependency. Peak (as opposed to current) RSS is only knowable from the OS: Windows tracks it in PROCESS_MEMORY_COUNTERS.PeakWorkingSetSize; POSIX reports it as ru_maxrss (KiB on Linux, bytes on macOS — normalised here). One syscall, called once per arm.
