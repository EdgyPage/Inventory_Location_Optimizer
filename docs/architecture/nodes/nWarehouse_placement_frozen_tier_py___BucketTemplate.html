class _BucketTemplate(dict)
A bucket template (`{aisle: {bracket: _Cursor}}`) that remembers how it was made: the per-aisle first appearances and bracket lists, the exclusion set its cursors agree with, and -- when derived -- its parent, the aisles that moved and whether the aisle order held. A plain dict to every reader (`_CowBuckets` reads it as one).
