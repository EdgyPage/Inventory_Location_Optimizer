def expected_task_labor(tasks: list, wp: WorkloadParams) -> dict
E[task labor] for a placement, scored ANALYTICALLY from the realised tasks. The optimization objective is the expected labor of a randomly-assigned task = mean over tasks of W = D + P + C (see Workload.aisle_workload). Computed straight from each Task's path/items via the same bracket-aware formula the sim bills, so it is independent of sim wall-timing (queue waits, parallelism, reorder starvation). Returns {'objective': mean W, 'handling': mean P, 'travel': mean (D+C), 'n_tasks': n}. 'travel' folds the cart-swap term C in with travel D since both are placement/route effects rather than per-unit handling; 'handling' is the placement-modulated P term.
