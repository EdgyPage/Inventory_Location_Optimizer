function clean_path

def clean_path(val: str) -> str
Strip `r"..."` / `r'...'` notation or plain quotes from an env-var path value. Applied after `os.getenv` as well as during parsing, so a value set directly in a Windows session environment (with literal `r"..."` text, which the shell does not interpret) is normalised exactly like one read from the file.
