class Singleton(Pallet)
Forward-pick / small-footprint storage. Singleton bins are a single fixed size (no small/medium/large/extra_large tiers). Any item whose two smallest dimensions both fit within 16×16 can be placed; items are rotated to minimise the stacking height. storage_size is always 'singleton' — one bucket per (handling, category), distinct from all pallet size tiers and never None so DB NOT NULL constraints are satisfied.
