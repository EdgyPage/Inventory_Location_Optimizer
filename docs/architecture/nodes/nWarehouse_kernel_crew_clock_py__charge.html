def charge(clocks, dur: float)
Book `dur` to whoever is free earliest; return `(start, worker_index)`. Greedy list scheduling. Ties break to the lowest index, so a crew of one is exactly a serial clock -- which is what makes a size-1 stream byte-identical to the single-clock model that preceded this.
