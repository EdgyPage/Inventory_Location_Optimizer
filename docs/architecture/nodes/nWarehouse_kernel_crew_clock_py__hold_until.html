def hold_until(clocks, idxs, t: float) -> None
Nobody in `idxs` may start before `t`: each clock becomes max(itself, t), IN PLACE. What dealing a worker to work that is not there yet means -- a trailer plugged into a door at `t` cannot be unloaded by a receiver whose clock says they were free earlier. A clock already past `t` is untouched (that worker is still busy).
