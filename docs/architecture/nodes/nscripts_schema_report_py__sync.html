def sync(out=print) -> int
Commit the DECLARED shape of every family that has not been committed yet. Idempotent. Run this BEFORE changing any DDL — and it is safe to run always, which is the point. A declared shape is re-derivable today and gone tomorrow; committing it is what makes the next change adoptable without an archive.
