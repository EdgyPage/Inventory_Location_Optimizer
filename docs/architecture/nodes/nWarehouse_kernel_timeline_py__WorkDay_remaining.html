def remaining(self, t_abs: float) -> float
Seconds left in the day containing `t_abs`. Never negative, never zero. Exactly at a boundary the answer is a WHOLE day, not zero: the instant belongs to the day that is opening. Returning zero there would stop a picker that has just started rather than one that has run out of time.
