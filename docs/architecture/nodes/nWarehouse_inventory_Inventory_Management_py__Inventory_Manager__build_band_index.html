def _build_band_index(self) -> None
Partition each free-bin tier list into per-band buckets, once, after the band maps are set. Anchors the O(#bands) `_band_pick` fast path; maintained incrementally thereafter by `_index_add`/`_index_remove`. Re-derives `_band_pos` from scratch, so it is correct regardless of whether bins were registered before or after zoning was enabled.
