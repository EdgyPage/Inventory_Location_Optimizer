def _check_tier(tier: FrozenTier, x_pace: float, y_pace: float, brackets) -> None
Refuse a slice whose tier was frozen under other paces or brackets. EXACT float equality, deliberately: the pool would compute these same values from the same `wp` through the same expression, and a tier that was not frozen from that `wp` carries different geometry -- a tolerance here would accept the mixed-warehouse mistake.
