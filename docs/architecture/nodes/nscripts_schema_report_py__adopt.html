def adopt(out=print, apply: bool=False) -> int
Report every committed shape no family vets any more - the outgoing shapes to adopt. Exit 1 when something needed adopting, so a hook or CI can catch a DDL change that shipped without its `known_ids` entry. With `apply`, the tuple edit is WRITTEN into the family's source (TODO-marked); the human keeps the commit-window comment and the commit itself.
