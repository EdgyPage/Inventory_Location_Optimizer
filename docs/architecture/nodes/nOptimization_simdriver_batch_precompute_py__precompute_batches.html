def precompute_batches(inv_db, max_skus, sku_allowlist, aff_db, batch_cfg, seed_batches: int, n_batches: int, workers: int=1, channel_regime=None) -> list
Return the full list of `Batch` objects for i in [0, n_batches). Serial when workers<=1 or n_batches<_MIN_PARALLEL; otherwise splits the range across a transient spawn pool (each chunk loads inv+aff once, then samples its slice). Result order is always 0..n-1.
