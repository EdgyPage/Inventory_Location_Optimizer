function _split_inflation

layer wh_inventory · file Warehouse/inventory/inventory_planning.py

def _split_inflation(split, a_w: int, bin_width: int) -> float
`1 / (1 - capacity_loss)` when an aisle split would actually cut this bucket's aisles, else 1.0 — the factor its demand replicas inflate by so the bins the split SACRIFICES do not come out of the declared levels ("Field the floor", decision 9). Mirrors `_aisle_split`'s own admission test (k > 1 after bounding by columns-per-segment and MAX_AISLE_SPLIT_K, loss < 1); a split that would not apply inflates nothing, so a configuration the emitter ignores never over-sizes the warehouse either.
