Optimization.sim_assets
sim_assets.py — per-pair shared-asset construction for a run. build_shared_assets loads the inventory+affinity pair once, sizes the warehouse (Inventory_Manager.plan_warehouse with the per-regime sizing from CONFIG), persists the planned inventory + warehouse stats (rename-proof fingerprint), and returns the picklable shared dict every strategy worker receives. Split out of run_simulation so the runner holds orchestration only; run_analysis imports this directly for its shape-only rebuild.
