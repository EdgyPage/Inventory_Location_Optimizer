def viable_storage_units(order: Order, quantity: int) -> list[StorageUnit]
Pack *quantity* items using the minimum number of full pallets, with any remainder routed to a singleton unit. Prefers Singleton over Pallet when the total item volume fits within a 'small' singleton slot (12 × 16 × 16 physical units), since singletons use a narrower footprint that leaves full-size pallet locations free. Otherwise, packs complete pallets at maximum capacity then routes the remainder to a singleton. Falls back to a partial pallet for the remainder if the order cannot be singletonised. Examples (max_per_pallet = 3, small_slot_vol = 3072) ------------------------------------------------------- volume*qty ≤ 3072 → 1 singleton × qty items (forward-pick preferred) quantity = 9 → 3 pallets × 3 items, no singleton quantity = 10 → 3 pallets × 3 items, 1 singleton × 1 item quantity = 2 → 0 pallets, 1 singleton × 2 items
