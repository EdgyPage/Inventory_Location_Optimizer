def staffing_provenance(explicit) -> dict
The staffing record's PROVENANCE block, one entry per input the regime reads. `declared` when a flag chose the value (`explicit` is the set of flag names typed on the command line), `assumed` when a settings default stood; the picker keys are `derived` under the era (ADR-0004), and a key the regime does not read -- None in `staffing_spec()` -- carries no provenance at all, because "assumed" would claim a settings default was in force when nothing read one. `floor_lines` under the era is `derived` unless typed (the coverage loop solves it).
