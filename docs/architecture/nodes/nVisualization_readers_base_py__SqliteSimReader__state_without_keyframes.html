def _state_without_keyframes(self, batch: int, aisles, t) -> dict
Last-resort path for a run written with keyframe_interval=0. `bin_inventory` holds one full snapshot (at the run's FIRST batch, which is not necessarily 0 on a resumed run) and depletion-only deltas after it. Ordering is by `batch_id, id`: the loop is last-write-wins and a bin can receive rows from two branches in one batch, so `batch_id` alone is not a total order.
