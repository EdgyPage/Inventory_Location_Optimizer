def _futuresight_batches(raw)
Normalize INBOUND_FUTURESIGHT_BATCHES for the spec: None | 'all' | int >= 0. Anything else raises here, at spec build, rather than reaching a worker: the knob denominates a batch COUNT, so a negative, fractional, bool, or unrecognized-string value is a config error, never a silent clamp — and the error names the knob (a bare `int('oracle')` message would refuse loudly but signpost nothing).
