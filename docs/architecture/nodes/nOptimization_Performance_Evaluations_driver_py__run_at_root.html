def run_at_root(ctx, keys, overrides, cli_set)
Run all run-scope evaluations named in `keys`, over the whole run root. Called by analyze_run AFTER every cell and after the cross-cell what-if writers: these evaluations read what those stages produced, so ordering is a data dependency, not a preference. Serial in the parent — there are a handful of them and each one reads the entire run, so a pool would buy nothing and cost the wipe-race rule.
