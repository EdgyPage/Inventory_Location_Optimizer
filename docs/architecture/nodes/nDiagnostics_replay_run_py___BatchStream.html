class _BatchStream
One table's rows, grouped by `batch_id`, consumed strictly forward. A cursor with one row of lookahead rather than a list: a single production arm holds millions of picks, and the fold only ever needs the batch it is currently applying. `take()` is a generator and MUST be drained before the stream is asked for its next batch.
