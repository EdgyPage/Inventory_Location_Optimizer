def compute_labor_cost(self, pick_intercept: float, pick_weight_coef: float, pick_volume_coef: float, pick_weight_fn: str='log', pick_volume_fn: str='log') -> float
Set (and return) labor_cost = per-unit pick regression cost for this order under the given PickConfig coefficients. Mirrors Pick._pick_time at qty=1, no cart swap, ground level. Call once per worker after inventory load. Also stores handle_var = the per-unit weight/volume term ALONE (without the intercept). labor_cost (= intercept + handle_var) is the qty=1 ground per-pick cost used to RANK items; the height multiplier scales the whole at-location pick at placement time: per-pick at height = mult*(pick_intercept + qty*handle_var).
