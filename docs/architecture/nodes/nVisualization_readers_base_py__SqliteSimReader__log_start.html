def _log_start(self) -> int | None
The first batch this run recorded a PLACE for, or None if it has no log. `MIN(batch_id)` on the `(run_id, batch_id, seq)` primary key, so it is an index seek, not a scan. None is the normal answer for every arm in the archive — those runs predate `bin_placement` — which is why the missing table is caught rather than raised.
