def unsplit(self) -> 'LoadPlan'
The plan the WHOLE shipment would have produced, arriving at once. Re-packs at `whole_qty`, which costs as much as the original packing -- hence a method and not a field. For a delivery that was not split this returns an equivalent plan, so a caller can compare unconditionally.
