def note_records(self, leaf, finish) -> None
`leaf` has stamped its unload rows; `finish` is the absolute instant its last one ended, or None when it recorded nothing. Called once per leaf per site day, on BOTH the picked and the skipped path — a batch that picked nothing still drained the dock. When the last leaf reports, the site carry is committed. THE RESET HAS ONE OWNER for exactly the reason the put pool says so: one leaf restarting a shared crew's clocks before the other has recorded is a silent, plausible-looking zeroing of a half-spent day. The carry moves only when somebody actually worked: no records anywhere means the crew is where it was, exactly as an unpooled leaf leaves `recv_clock` alone.
