def check_completeness(shape_tables: dict, family: str) -> list
Problems between a family's declared shape and its declared semantics. `shape_tables` is `Family.declared_shape()['tables']` verbatim — {table: {'columns': [{'name', 'type', 'notnull', 'pk'}, ...], ...}} — consumed directly so there is no parallel column list to drift. For every COVERED table: every column tagged, no tag naming a vanished column, null-meaning present wherever the DDL allows NULL, and a clock wherever the unit is time. Empty list = the gate passes.
