def _runtime_dir(run_root: str) -> str
The run-root runtime-PNG directory, from the contract's `runtime_pngs` template. The glob star sits in the FILENAME segment, so the template's dirname is the output dir — the underscore prefix it carries is what makes every tree walker (cells / iter_channel_runs / the cross-cell whatif scans) skip it, the same reserved-dir convention as the frozen assets and the aggregate subtree. A root with NO descriptor (ad-hoc trees) falls back to the HEAD contract, which renders exactly the string the old literal join produced.
