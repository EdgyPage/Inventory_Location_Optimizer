def _ro(path: str) -> sqlite3.Connection
Open `path` strictly read-only — `Schema.connect.read_only`, the sanctioned opener. Never `Picking_Data._open_db` (its `PRAGMA journal_mode=WAL` is a WRITE), and never immutable: the viewer may be watching a run that is still being written. This used to be a hand-rolled URI connect; the broker-boundary ratchet now forbids `sqlite3.connect` outside `Schema/connect.py`.
