def _declaration(ctx, pair: str) -> dict
The coverage this run DECLARED for `pair` — the three knobs, off the staffing record. The run states its own inputs; this never re-derives them. Read defensively because an absent declaration is DATA: a run whose assets were rebuilt from a frozen inventory, or one that predates the coverage loop, records no `coverage` block, and the right report for it is "the file's levels, declaration unrecorded" rather than a raise or an invented default.
