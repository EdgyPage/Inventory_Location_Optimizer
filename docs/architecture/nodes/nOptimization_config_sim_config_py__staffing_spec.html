def staffing_spec() -> dict
The staffing record's INPUTS as a picklable dict, one entry per STAFFING_KEYS key. Inputs ONLY -- the derived block (batch content, put crew, receiving crew, expected utilization) is the pure module `Optimization/simconfig/staffing.py`, run by `workunits._derive_staffing_for_pair` after batch precompute, and is never a CONFIG key. Read from CONFIG at call time for the reason every accessor in this file is, and carried in `workunits._shared` so a spawned worker can check that the crews it was handed are the crews the record declares. The pickers resolve through `channel_pickers` (a None is the leaf default); the scalars resolve a None to their settings default (`_SCALAR_DEFAULTS`); the CALIBRATION_KEYS keep None, because "no override" is a value the calibration loader reads.
