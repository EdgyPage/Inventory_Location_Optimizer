One strategy's per-batch production-labour frame, memoised. Takes BOTH sibling frames: the batch frame states which batches happened (so a batch that put nothing away is present at zero rather than missing) and the task frame carries the pick leg, which `work_events` structurally cannot — a pick row is an instant with a NULL duration, and the work is the span between two of them.
