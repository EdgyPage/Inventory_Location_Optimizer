def ordering(fn)
Tag `fn` as an ORDERING entry: `(candidates, ctx) -> ordered list`. The registries hold both kinds; this attribute — probed via getattr, the `STANDING` idiom — is how `bounded_order` tells a whole-order proposal from a per-candidate key. The return must be a PERMUTATION of the candidates handed in (the same objects): `bounded_order` raises on anything else, because a silently dropped trailer would stand in the yard forever and a duplicated one would stage twice — neither with an error.
