def staleness(rec: dict, warehouse_fingerprint: str | None) -> dict
The two stamps the staffing record carries about the record it ran under. `calibration_stale` is True only when the record NAMES a fingerprint and the run's differs; `calibration_measured` says whether there was a measurement to be stale against at all. Both False is the seed on any catalogue; False/True is a measured record on its own catalogue; True/True is the warning case.
