def release(self, now_s: float | None=None) -> list
Everything the dock can start on this batch, as [sku, qty, 0] deliveries. Order of operations IS the model: (1) anything still loading departs — a trailer waits for nothing in v1; (2) arrivals (lead elapsed against `now_s`) join the yard; (3) the yard stages to doors and staged trailers are worked in GLOBAL-priority order, each trailer's pallets in LOCAL-priority order, emitting one delivery per contiguous SKU lot — so a split shipment packs as the pieces it arrived in. Worked trailers free their doors within the drain (v1: doors are bookkeeping; see the module note).
