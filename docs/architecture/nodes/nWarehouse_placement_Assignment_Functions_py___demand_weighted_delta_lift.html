def _demand_weighted_delta_lift(affinity: AffinityStore, sku: int, member_idx_set: set[int], freq_by_idx: dict[int, float]) -> float
Sum of (lift(s,i) − 1) * f_i for all affinity partners i in the aisle. Same CSR row-slice as delta_lift_idxs but weights each partner's association ABOVE independence (lift − 1; lift = 1 ⇒ 0) by its demand frequency, so common strongly-associated partners dominate over rare or near-independent ones. Delegates to the row helpers so the cold path (place_one, sort keys, tests) and the hoisted hot path (_delta_lift_from_row with a pre-built row) share ONE arithmetic path — bit-identical, both promoting the CSR float to Python float before the sum.
