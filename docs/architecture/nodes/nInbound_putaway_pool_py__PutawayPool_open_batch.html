def open_batch(self, index: int) -> tuple
`(base, deadline)` for site day `index`: the put crew's absolute epoch and the whistle as a REMAINDER on the batch-local clocks. IDEMPOTENT PER INDEX, and that is the contract: every leaf asks, and every leaf must get the same answer, because one clock list cannot carry two epochs. The first call computes; the rest read. `base` is `max(day.start_of(index), put_clock)` — the putters start at shift start and work what is on the dock, or they carry on from where yesterday's overrun left them. `deadline` is the rest of the day CONTAINING that base, so base + deadline is the day's end however far the carry has run.
