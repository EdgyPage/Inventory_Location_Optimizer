def source_fingerprint(repo_root: str=_REPO_ROOT) -> str
Hash of every shape-defining source file (path + content), in declared order. Line endings are NORMALISED to \n before hashing. On Windows a checkout, stash/pop, or autocrlf change rewrites CRLF<->LF without touching a single statement; hashing raw bytes made that look like a structural change and cost a needless canary pair. Content changes still register, which is the whole point. A missing file contributes its path plus a MISSING marker rather than being skipped, so DELETING a shape source is detected instead of silently matching.
