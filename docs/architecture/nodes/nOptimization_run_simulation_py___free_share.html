def _free_share(text: str) -> float
An argparse `type=` for a free share of a bin bucket: a number in [0, 1). Zero is a real setting ("trust the fragmentation chain, no floor"); one is a bucket sized for nothing, and the derivation would divide by `1 - 1`. Fails at the parser, naming the flag, rather than as a bare ValueError at run-spec build after the run dir exists (`sim_config.min_headroom`).
