def glob(self, artifact: str, **parts) -> list[str]
Existing paths for an artifact, with UNSUPPLIED parts wildcarded. Generalizes `whatif_outputs()`: any `{part}` not passed becomes `*`; template `*`/`**` pass through; the optional `{channel?}` level expands to BOTH variants (with and without the segment) because a single glob cannot express an optional directory. Sorted, deduped, absolute; only existing paths return.
