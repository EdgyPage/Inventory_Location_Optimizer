def cache_status(self) -> str
'fresh' | 'stale' | 'absent' | 'partial' — re-checked, never pinned. Freshness matters on the READ path, not just at build time: an arm rebuilt by a strategy-granularity resume gets a brand-new sim DB and its own `run_id = 1`, so a stale sidecar's rows collide by key and the viewer would keep serving the PREVIOUS run's `final_home` (the colour authority) and occupancy with nothing to signal it.
