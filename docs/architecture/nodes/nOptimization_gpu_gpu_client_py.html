Optimization.gpu.gpu_client
gpu_client.py — worker-side GPU offload shim + the shared tiled cost-matrix kernel. The placement drain scores, for a wave of U queued units over C candidate bins of one BinKey, the static marginal cost cost[u,b] = v[u]*M[b] + (M[b]*intercept + D[b]) and takes argmin over bins per unit. This module owns: * `estimate_bytes(U, C, tile)` — the allocation calculator (admission + startup ceiling). * `cpu_argmin(...)` — the numpy CPU reference / fallback (tiled; bounded memory). * `GpuClient` / `placement_argmin(...)` — offload to the broker; returns None ⇒ caller does CPU. `placement_argmin` NEVER raises and NEVER blocks indefinitely: a missing/over-budget/timed-out/ errored broker yields None so the worker silently runs the CPU path — an unattended run can't crash on GPU trouble. The broker (gpu_broker.py) reuses the same tiling math on the GPU.
