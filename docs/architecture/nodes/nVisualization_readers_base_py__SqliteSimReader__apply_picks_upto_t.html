function _apply_picks_upto_t

layer visualization · file Visualization/readers/base.py

def _apply_picks_upto_t(self, con, bins: dict, batch: int, t, scope: str) -> None
Subtract batch `batch`'s own picks up to sim_time `t`. No-op when `t` is None. This is the intra-batch clock: `picks.sim_time` is the finest resolution the record has, and it is unaffected by the log (restocks carry no sub-batch time — `check_reorders()` runs entirely between two batches' simulations).
