def _generalize_file(segments: list[str], axes: dict[str, set]) -> str
Turn a run-root-relative path into a template, consuming levels POSITIONALLY. Positional consumption is the whole point: `<pair>/store/store/` is a real path where the config and the channel share a name, so any name-based guess is wrong. Each level is taken only at its own depth, and only if the segment is a known value for that axis.
