Optimization.simconfig.configs.ful_calibrated
Fulfillment channel — base human-walker pick-config (FulfillmentCart, one-way lanes). The FIRST/only fulfillment entry is the single source of truth for the default walker cost — channels.fulfillment_pick_config() reads it back via sim_config.FULFILLMENT_CONFIGS[0]. Keep the name DISTINCT from any store config name (config.json is written per config dir; a shared name would collide — see the runner's _prepare_channel_run).
