function _migrate_setup_columns

layer opt_persistence · file Optimization/persistence/runtime_metrics.py

cross-layer
def _migrate_setup_columns(con) -> bool
Add the setup-phase columns to a DB written before they existed; True if it changed. `CREATE TABLE IF NOT EXISTS` cannot widen an existing table, so a finished run whose arms predate these columns needs an explicit ALTER before a backfill can write to it. Every added column is NULLABLE with no default, so existing rows read NULL — "never measured", which is exactly what they are. Re-stamping afterwards is not optional: the file's recorded schema id describes its old shape, and leaving the two disagreeing turns every later read into an unvetted warning. A migrated run legitimately IS the current shape.
