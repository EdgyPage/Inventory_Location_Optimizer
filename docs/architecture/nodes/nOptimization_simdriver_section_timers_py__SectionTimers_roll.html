def roll(self) -> None
Close the open window: fold it into the base and zero it for the next one. Nothing depends on this having happened — `total()` already counted the window. Rolling an empty window is an exact no-op (`x + 0.0 is x` for every float a timer holds), so an extra roll cannot perturb a total.
