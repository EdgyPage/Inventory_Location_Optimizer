class Cell

layer opt_simdriver · file Optimization/simdriver/cells.py

class Cell(NamedTuple)
One point in the what-if matrix: a fixed choice on every swept axis. A NamedTuple rather than a dataclass, deliberately. This was a bare 4-tuple unpacked positionally in five files — `cells.py`, `scenario.py`, `run_simulation.py`, `sim_manifest.py` and `run_whatif_delta.py` — so `c[1]`, `c[3]` and `(name, split, zoning, sched) = c` all had to keep working. They do, which is why this change cannot break a consumer by being half-applied; named access is simply added beside them. The FIFTH axis (the inbound policy) is now one field and one line in `_build_cells` rather than five positional unpacks to find and renumber. The names here are the same ones the run-tree descriptor records, so it and the producer cannot drift apart.
