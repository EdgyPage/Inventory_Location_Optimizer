def _site_unload_cost(leaf_args: dict)
ONE channel's entry in the site dock's price list (site-dock 27). The SAME chain a leaf builds for its own dock, evaluated against THIS channel's pick config: pickers -> put-away (`PutawayCost.from_pick`) -> receiving (`UnloadCost.from_putaway`), then the inbound spec's own coefficients overlaid. Built from the leaf payload rather than copied off the leaf, because the dock exists before any leaf does -- and because re-deriving it here from the same inputs is what makes the two entries provably the two constants an uncoupled run already charges.
