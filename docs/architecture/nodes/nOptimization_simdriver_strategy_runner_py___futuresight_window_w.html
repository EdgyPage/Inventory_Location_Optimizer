def _futuresight_window_w(spec, batches)
The futuresight window width — `int` batches or `'all'` — or None when neither standing policy names the arm. This is the arm's REFUSAL-UNTIL-CLEAN gate ("Define the inbound objective" decision 6), checked once at worker startup: * the knob unset is a config error, never a silent default — an unlawful reference arm must be run on purpose, with its window stated; * `batches` None means this worker fell back to INLINE batch sampling (fingerprint miss / missing script), and a window sampled inline would be a silently different future than the one the run releases. The script is REQUIRED; the run refuses before simulating a single batch.
