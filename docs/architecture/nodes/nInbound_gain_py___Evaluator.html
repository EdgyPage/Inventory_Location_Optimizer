class _Evaluator
One plan's virtual placement state — built per entry call, dies with it. Owns the sort-once structures (per-key bins in arm-D order, computed lazily the first time a key is touched and NEVER rebuilt — the structure the Tier-1 sabotage test perturbs), the consumed-bin set the greedy advances, and the pricing. Reads the frozen `SpaceView` and the bundle; its only writes are its own bookkeeping.
