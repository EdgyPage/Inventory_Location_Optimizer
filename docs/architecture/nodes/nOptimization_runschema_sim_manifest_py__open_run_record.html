def open_run_record(base_dir: str, record: dict) -> int
Append a launch record and return its ATTEMPT NUMBER (1 for the first). Called after the preflight gate, at the one point where the whole construction is in scope: before it, a failed preflight's cleanup could tear a record that describes a run that never began. `resume_of` and `attempt` are derived HERE from what is already on disk rather than passed in, so a caller cannot get the chain wrong: the attempt is the count of records already present plus one, and `resume_of` is the previous record's `started`.
