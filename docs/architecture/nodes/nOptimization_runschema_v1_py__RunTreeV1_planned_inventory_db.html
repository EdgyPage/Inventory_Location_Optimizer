def planned_inventory_db(self, cell: str, pair: str) -> str
The planned inventory for (cell, pair). Multi-cell runs freeze it once at _frozen/<pair>/ and share it across cells; single-cell runs write it under <cell>/<pair>/. Prefer whichever exists, frozen first — that mirrors build_shared_assets, which returns the frozen DB verbatim when one was supplied.
