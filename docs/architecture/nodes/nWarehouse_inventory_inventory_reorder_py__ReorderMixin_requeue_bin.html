function requeue_bin

layer wh_inventory · file Warehouse/inventory/inventory_reorder.py

cross-layer
def requeue_bin(self, bin_: 'Aisle.Bin') -> None
Evict a placed unit back into the reorder queue and reclaim its bin — the inverse of _execute_placement. The unit's quantity moves from on-hand to on-order (queued), so inventory POSITION is unchanged (no spurious reorder fires). The freed bin returns to the available index and the ranked drain re-places the queued unit in its proper priority slot. Bumps the reload churn counter. No-op on an empty bin.
