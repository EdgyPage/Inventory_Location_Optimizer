def _rule_order(rows)
One rule order for every panel of the family, cheapest-first by the FIFO multiple. Sorting each panel by its own values scrambles cross-channel reading: a reader following one rule has to hunt for it again in the next panel. The multiple is the right key because it is the family's primary view and it is unit-free.
