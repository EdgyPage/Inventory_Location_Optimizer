def run_dirs() -> tuple
Every declared out_subdir of a RUN-scope evaluation, deepest-safe creation order. The config stage needs the shared-top/single-owner distinction because its evaluations run in a worker pool and two owners must not race to wipe one directory. Run scope has no such hazard — `analyze_run` executes these serially in the parent, after every cell is finished — so the whole `_dossier/` root is wiped once and every declared subdir is recreated, with no ownership rule to get wrong.
