def epochs(durations: Iterable[float]) -> list[float]
The absolute start time of every batch — `[0, d0, d0+d1, …]`, one per batch. The whole-series form, for a caller converting a run to one timeline in a pass. This is the arithmetic `run_whatif_volume` performs with `np.cumsum`, offset by one: cumsum gives each batch's END, this gives each batch's START.
