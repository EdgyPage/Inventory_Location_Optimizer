layer visualization · file Visualization/db_reader.py

def _tree_stamp(base_dir: str) -> tuple
A cheap key that changes when the tree gains an arm or is replaced. One `os.walk` (~0.15 s even on the results drive) over the run descriptor's mtime plus the number of `sim_*.db` files. A finished run is static, so this is stable; a run still being written gains arms, and the count catches that without re-opening 272 databases.
