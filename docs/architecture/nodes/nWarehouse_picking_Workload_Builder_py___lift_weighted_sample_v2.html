def _lift_weighted_sample_v2(candidates: list, k: int, affinity: 'AffMatrix | AffinityStore | None', rng: random.Random | None=None) -> list
Fenwick-tree form of `_lift_weighted_sample`: same conditional-demand weight model (weight(B) = freq(B) · Π lift(A,B) over selected partners A), O((k·(1+P))·log n) instead of v1's O(k·n) full-array passes per draw. NOT byte-compatible with v1 — the tree groups float additions differently than v1's sequential cumsum, so draws eventually land on different SKUs and the batch sequence is a new version (BatchConfig.sampler='v2'; batch_precompute fingerprints it apart). Deterministic for a given rng seed, one rng.uniform consumed per draw like v1.
