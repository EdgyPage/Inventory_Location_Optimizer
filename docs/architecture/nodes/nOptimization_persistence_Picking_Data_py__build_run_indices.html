def build_run_indices(path: str) -> float
Build every index in one pass, after every row is in. Returns the seconds it took. IT RETURNS THE SECONDS BECAUSE THE CALLER MUST CHARGE THEM. Deferring index maintenance does not delete the work, it relocates it — and relocating cost out of a measured window into an unmeasured one reads as a saving and is a lie. `strategy_runner` adds this to the same `save` section the per-checkpoint writes are charged to, so `runtime_metrics.save_s` still accounts for every second of it.
