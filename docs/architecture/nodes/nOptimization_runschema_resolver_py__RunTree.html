class RunTree
Resolver for one run directory. Construct via ``runschema.resolver_for(base_dir)``. Every accessor returns an ABSOLUTE path (or an iterator of them). Existence is NOT implied — optional artifacts legitimately do not exist on some runs (see each artifact's `condition`), so callers check `os.path.exists` where it matters.
