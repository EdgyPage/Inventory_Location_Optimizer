def pin_digest(derived: dict) -> str
A 12-hex identity for `pin_of(derived)` -- the one string a campaign spec carries. The projection itself is recorded on `restock_selection.json` so a refusal can be DIAGNOSED (which crew moved, which price), and only this travels into the spec: a pin the size of the projection would be twenty hand-copied floats in a tracked file, and a typo in one of them is indistinguishable from the drift it exists to catch.
