Optimization.run_simulation
Warehouse assignment strategy simulation runner. Runs A/B/C strategy workers for each (pair × regression-config) combination and saves all results to per-strategy SQLite DBs. Graph generation is a separate step: run_analysis.py <base_dir>. Modes: python run_simulation.py # new run, sequential python run_simulation.py --workers 15 # flat pool, no idle python run_simulation.py --resume <base_dir> # resume a crashed run
