def new_clocks(size: int, what: str='crew') -> list
`size` idle workers. Raises below 1, because a crew of nobody is a configuration error rather than a crew that does nothing slowly. `what` names the owner in the message -- a queue name, a dock name -- so a bad size in a multi-stream configuration says WHICH stream.
