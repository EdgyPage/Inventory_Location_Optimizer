backbone
def _run_pool(remaining, meta, max_workers, recycle, log, done_uids, finalized, cell='', run_root=None)
One ProcessPoolExecutor lifetime over `remaining` [(uid, args)]. Returns (failed_uids, broke). A genuine success adds uid to done_uids and finalizes its group once ALL members succeeded; a hard worker death (BrokenProcessPool) sets broke and abandons the rest so the driver can rebuild + resubmit; an ordinary worker Exception is isolated. `cell` is prefixed on every per-arm tag so interleaved multi-cell output is attributable.
