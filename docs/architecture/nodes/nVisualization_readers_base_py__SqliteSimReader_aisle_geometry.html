layer visualization · file Visualization/readers/base.py

def aisle_geometry(self) -> list[dict]
One row per aisle — never a per-bin list. Materializing every bin for all 384 aisles is ~396,500 dicts and a ~40 MB JSON response per pane; the grid is regenerated from bay_x x bay_y wherever it is actually drawn. Also assigns each aisle its palette coordinates: `family_index` (which of the 13 hue anchors) and `family_ord` (its rank inside that family's hue band, ordered by category then aisle_id so same-category aisles sit adjacent).
