def fill_rate(orders, lines_per_day: float) -> dict
The expected FIRST-PASS fill rate of one section at the levels the orders carry now: the units a shelf at `Q_s` serves off a line, over the units the line asks for, weighted by each SKU's lines per day ("Choose the coverage floor", decision 5): Σ_s lines_s · E[min(q_s, Q_s)] ÷ Σ_s lines_s · E[q_s] lines_s = n · π_s The denominator is the section's daily units; the numerator the units served before a restock. Under base stock with NO pipeline (`pipeline_qty = 0`: a lead of zero, which is every catalogue the generator authors today) the shelf sits at `Q_s` when every line arrives -- the previous line's order landed -- so this IS the expectation `missed_share`'s level is read against: `1 - fill_rate` is the expected missed share. With a lead the shelf a line meets is `Q_s` minus what is still in transit, so the number is an UPPER bound on the fill rate there (the record carries the stamped pipeline beside it). Call it on the PLANNED orders -- the planner may grow a level into leftover capacity, and the shelf that serves the line is the one the run fields. Returns `{'fill_rate', 'expected_missed_share', 'units_per_day', 'served_per_day', 'base_stock_skus', 'base_stock_share', 'n_skus', 'pipeline_units'}` -- the last is Σ `pipeline_qty` over the section, 0 when the premise holds exactly.
