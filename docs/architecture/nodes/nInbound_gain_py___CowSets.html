class _CowSets
Copy-on-write over `{aisle: set}`. Unlike floats, the value is MUTABLE and the caller does `d[aid].add(sku)` -- and `__getitem__` cannot tell that from the `sku in d[aid]` two lines above it. So an access materializes that ONE aisle's set. Bounded by the aisles a pool touches (measured 1.22), not by the warehouse (46).
