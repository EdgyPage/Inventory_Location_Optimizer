def _aisle_split(a_w: int, target_bins: int, eff_fn, bin_width: int, k, capacity_loss)
Cut an aisle of width `a_w` (holding `target_bins` bins for its bucket) into `k` shorter segments of width ~a_w/k, modeling cross-aisle throughways that consume `capacity_loss` of the bins. Under one-way lanes, shorter aisles ⇒ less x-traversal. Returns (seg_w, n_segments, seg_eff, cap_total) or None (no split ⇒ byte-identical caller path). `eff_fn(width) -> bins-per-segment` (uniform_aisle_bins or catalog_aisle_bins bound to the tier). k is bounded to ≤ a_w // bin_width (≥1 column/segment) and ≤ MAX_AISLE_SPLIT_K so the emitted aisle count cannot blow up. Total usable bins ≈ target_bins·(1-capacity_loss) — bins are genuinely SACRIFICED (no compensatory aisles added), so aggressive loss raises fill by design.
