def _bind(db: str)
Bind a sim DB to its OWN schema vintage (`Schema.dataset.bind`), or None if unvetted. None routes the caller to the frozen pre-registry read path (`connect.read_only` + a PRAGMA probe) — synthetic test fixtures and cold-archive vintages keep exactly their historical behavior, the same vetted/unvetted split `Picking_Data._query_rows` uses. A VETTED file that cannot serve the declared read raises `RequirementUnmet` naming the missing column instead of degrading: failing loudly at open is the whole point of the declaration.
