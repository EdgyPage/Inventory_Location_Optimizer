def prepare_site_dir(out_dir)
Wipe + recreate one pair's `site_dir` analysis root, then its declared subdirs. The site DB lives in this same directory and is the SIMULATION's output, not the analysis's — so this wipes the analysis SUBDIRS and never the root, unlike `prepare_run_dir`. Wiping the root here would delete `inbound_<arm-pair>.db` and every later re-analysis of the same run would find no yard at all, which reads exactly like an inbound-off run.
