The put-away queue. A live deque while there is ONE queue -- which is the default, and why every existing consumer, mutation site and test keeps working unchanged. With the streams split there is no single deque to hand back, so this returns a read-only view and any code that tried to mutate it would fail loudly rather than mutate a copy. Internal drain code takes a `PutQueue` explicitly and never reaches for this.
