function _tightest_split

layer opt_simdriver · file Optimization/simdriver/cells.py

def _tightest_split(cells)
The split with the largest capacity_loss. Freezing the sampled inventory to it is how a multi-cell sweep guarantees every cell can hold the same inventory. "Largest loss" no longer means "fewest bins", and has not since "Field the requirement": `_split_inflation` adds compensatory aisles at sizing time, so a lossier split can emit MORE bins than no split at all. The freeze is still correct, and now for a stronger reason -- every cell is sized from the same declaration and REFUSES if it cannot hold it, so which split we freeze against no longer decides whether the inventory fits. Kept as the freeze point because the choice must be deterministic and cell-order-independent.
