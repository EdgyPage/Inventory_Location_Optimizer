function dock_depth_for

layer inbound · file Inbound/receiving.py

orphancross-layer
def dock_depth_for(self, leaf) -> int
Storage units of THIS leaf's merchandise standing on the site dock floor. The site-scoped replacement for `Inventory_Manager.dock_depth`. A LEVEL, so it neither drains nor resets and may be read at any instant -- unlike `snapshot_for`, which is a per-site-day drain and can be taken once. Zero on every standing-yard run by construction: merchandise waits on a trailer until a receiver pulls it, and `accept` hands it straight to the put queue. Written out anyway, because "the floor is empty" is a fact about the standing model and not a licence for the caller to assume it.
