class SpaceView
One drain's frozen view of warehouse space — pure data, copied at freeze. Policy keys read it as `ctx.space` (None when no standing yard runs). The staging decision anchors to `empties` — immediately available bins, the operationally stable signal; `predicted` rides as data for the planning formulation still being designed ("Define the inbound objective"). NO aggregates live here: what gets derived from the tiers is the evaluator's business. The container sets are FROZEN copies (the live `_index` lists swap-remove mid-drain, so a held reference would violate the frozen-ctx contract); the `Bin` objects inside are the live ones — a key that reads `bin.storage` mid-drain is reading stale-by- design data, exactly as the `put_policy` purity contract states.
