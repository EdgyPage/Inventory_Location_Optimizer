Optimization.run_whatif_delta
run_whatif_delta.py — compare what-if scenarios against a reference cell. Reads the steady-state ss_prod_hours (total labor) and ss_thr (throughput) straight from each scenario's sim_*.db (no run_analysis needed), keyed by (pair, pick-config, channel, arm), and diffs every cell against the reference cell. Emits whatif_delta.csv + a labor-saving-vs-throughput-gain scatter (one point per cell×channel×arm) and a median summary — tracking BOTH axes, since for fulfillment the throughput gain is the interesting lever (total labor is cart-swap-dominated). python -m Optimization.run_whatif_delta <comparison_whatif_...> # --reference defaults from config
