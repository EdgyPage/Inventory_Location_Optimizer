def archive_keyframes(rt, cell: str, cold: str, *, dry_run: bool=False, echo=print) -> dict
Move only the keyframe DBs — the one family with no downstream reader. This is what remains possible when the hot volume cannot hold a junction. Keyframes are ~19% of a cell and are read by NOTHING in the analysis path: not run_analysis, not the rollup, not either what-if scan. The replay viewer is the only consumer and it already degrades to an empty string when the file is absent. So they can simply leave, with no link and no path rewriting.
