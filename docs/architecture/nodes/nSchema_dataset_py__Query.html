@dataclass(frozen=True, eq=False)
class Query
One named read: hand-written SQL whose OUTPUT columns are a stable logical vocabulary. `columns` is the contract consumers bind to — every override must yield exactly the same set. `optional` maps logical names that may be absent on some vintages to their default value; the canonical/override SQL simply omits them and `Dataset.query` fills the default, which is the registry form of the loaders' `row.keys()` guards. `tables` names what the CANONICAL sql touches, so servability can be answered from the bound shape without parsing SQL.
