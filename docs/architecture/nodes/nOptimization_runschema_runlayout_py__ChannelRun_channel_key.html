def channel_key(self) -> str
The channel this run SIMULATED, spelled as every writer's `channel` column spells it. `channel` is the run-tree LEVEL, and it is None on a store-only layout because there is no `<channel>/` directory to name. The channel itself is not absent: a non-mixed catalogue yields store runs only (`workunits._channel_runs_for`), and those arms wrote `channel = 'store'`. So the missing level means STORE, never 'no channel', and a reader that spells it `''` silently matches no row — which is what `run_map_precompute`'s runtime lookup and its `WHERE channel=?` backfill did.
