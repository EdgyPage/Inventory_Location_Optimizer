layer inbound · file Inbound/gain.py

def _merge_only(ev, loads, _load, predicted: bool) -> bool
True when `_plan_order_replay` is exact for this plan: every group of every load resolves to the merge rung, the greedy starts from nothing taken, and (with `predicted`) no predicted bin is also an empty bin of its tier -- the one way a predicted bin could sit in an exclusion set, which the frontier form cannot see. Resolution goes through the same `for_key` the placement will call; an owner that raises there is left to raise on the set-algebra path, where the message was always written, rather than here.
