def _build_cells(spec)
Combinatorial (scheduler × zoning × k × capacity_loss) cells from a WHATIF spec. k=1 = no split (loss collapses to 0). Returns [(name, aisle_split|None, zoning_spec, scheduler), …]; the (k=1, off, round_robin) cell is the natural reference. ``schedulers`` defaults to ['round_robin'] (byte-identical, no name suffix); a multi-value list adds a `_rr`/`_lpt` suffix so the picker-scheduler becomes a sweep axis alongside aisle_split and zoning.
