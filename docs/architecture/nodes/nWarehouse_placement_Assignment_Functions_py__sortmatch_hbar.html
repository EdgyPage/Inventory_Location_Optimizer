def sortmatch_hbar(orders, wp) -> dict
{id(regime wp): hbar} -- the demand-weighted mean at-location cost of one pick LINE over the catalogue, per regime: hbar = sum_s f_s (I + E[q_s] (p + v_s)) / sum_s f_s `I`, `p` from the SKU's own regime parameters (`_wp_for`), `E[q]` the SKU's stamped line law, `v` its handle variance. It is the rate at which a bin's height multiplier trades against its travel D for the average line, so `D + hbar M` is ONE number that ranks bins the way the billing law does for a typical pack (`build_sortmatch_pool_fn`). Keyed by the resolved parameter object so a single-regime run (no `by_regime` map) has one entry and a mixed one has one per regime.
