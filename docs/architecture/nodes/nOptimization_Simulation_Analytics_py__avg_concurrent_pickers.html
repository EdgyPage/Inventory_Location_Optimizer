def avg_concurrent_pickers(events: list) -> float
Time-weighted average number of pickers simultaneously in 'picking' state. A picker is "picking" from the moment they arrive at a bin (arrive event) until they finish handling it (pick event). Cart-swap overhead is folded into that interval because both arrive and pick share the same pick_time span. Algorithm --------- Build a (time, +1/-1) change-list, sort it, then sweep to integrate the concurrent-count curve. Divide by total simulation span.
