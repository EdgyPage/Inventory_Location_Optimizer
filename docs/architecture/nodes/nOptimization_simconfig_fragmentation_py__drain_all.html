function drain_all

layer optimization · file Optimization/simconfig/fragmentation.py

def drain_all(state: State, d_max: int) -> dict
`{d: {state: weight}}` for every `d = 1..d_max`: the shelf after `d` items are picked smallest-first, in ONE pass (the drain of `d + 1` is the drain of `d` and one more). A tie between units of equal quantity and different kind is split uniformly over the tied UNITS (the layout's location order is uninformative across tiers -- module docstring -- so each tied unit is equally likely to come first); branches are merged after every whole unit, so a shelf of many tied units costs its distinct multisets, not its orderings. A `d` no unit can satisfy yields nothing for that `d` (the caller only asks below the shelf's total).
