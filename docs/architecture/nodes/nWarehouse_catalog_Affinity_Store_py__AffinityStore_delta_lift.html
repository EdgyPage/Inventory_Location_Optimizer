def delta_lift(self, sku: int, aisle_members: list[int]) -> float
Association ABOVE independence between sku and aisle_members: Σ (lift − 1). Lift is a multiplier with 1 = independence, so the co-location *value* of a partner is (lift − 1); unstored pairs (lift = 1) contribute 0. Walks the CSR row for sku directly — bounded by sku's partner count, regardless of aisle_members length.
