function _units_of_cell

layer optimization · file Optimization/run_unload_ranking.py

def _units_of_cell(rt, cell: str, cell_dir: str, threshold_days: float, log) -> list
One row per unit of the cell: its rule pair, stock mode, score, census and overage. The score and the census are read from the SAME series document in the same pass, and both are summed over the unit's two leaves. They must travel together: a score is only a placement result to the extent its census is zero.
