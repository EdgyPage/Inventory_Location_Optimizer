def batch_epoch(durations: Sequence[float], index: int) -> float
Absolute start time of batch `index`: the sum of every batch before it. `durations[i]` is batch i's makespan, in the sim's own unit. Adding this to a picker-local `t` puts an event from any batch on one axis — which is what a trailer arriving on a schedule, or a slot freeing four batches from now, has to be measured against. Raises on a negative index rather than silently wrapping, because `durations[-1]` is a real batch and would produce a plausible wrong answer.
