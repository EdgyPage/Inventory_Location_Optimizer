def submit(self, cell, jobs) -> int
Queue one cell's jobs (any iterable of `Job`), dispatch as far as the pool allows, and return how many were queued. A key already DONE for this cell is skipped -- a rebuild after a break hands back every job of the cell, finished ones included.
