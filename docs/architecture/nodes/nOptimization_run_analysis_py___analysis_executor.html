function _analysis_executor

layer optimization · file Optimization/run_analysis.py

def _analysis_executor(max_workers: int)
The analysis pool's executor: a spawn `ProcessPoolExecutor` WITHOUT the sim pool's recycling pin (`supervisor._sim_executor`). Analysis jobs are seconds long, and `'graph'` granularity co-schedules the graphs of one leaf on whatever worker gets them, reusing a loaded context (`_CFG_CTX` and its siblings) -- a fresh process per job would reload the context per graph. The caches are evicted per CELL in `_run_job` instead, so one pool over ten cells does not hold ten cells' contexts.
