models -- the composed closed-form models, one module per question. Each module builds `Warehouse.kernel.closed_form.Model`s out of the kernel's expression tree and the existing closed forms beside it (`coverage`, `staffing`, `expected_travel`, `fragmentation`), which enter through `Call` nodes rather than being re-implemented.
