function fill_at

layer optimization · file Optimization/simconfig/equilibrium.py

def fill_at(curve: list | None, transit_days: float) -> float | None
The record's fill-versus-transit curve (`era_coverage.fill_curve`, `[{'transit_days', 'fill_rate'}, ...]` sorted by transit) read at `transit_days`, linearly between points and held at the ends; None without a curve. The one interpolation the audit does: the curve is the closed form evaluated at the stamp's own law with the median scaled, so between two points it is the same section under a slightly faster or slower road.
