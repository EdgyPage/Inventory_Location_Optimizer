def configure_zoning(self, enabled: bool, n_bands: int=3, orders: Any=None, *, mode: str='equal', abc: dict | None=None) -> None
Enable/disable velocity zoning and precompute the band maps (once, before stocking). mode='equal' (default): SKUs and aisles sliced into n_bands EQUAL-COUNT groups (hottest / shallowest = band 0). mode='abc': SKUs banded by cumulative demand-MASS thresholds (abc['mass_thresholds'], manual A/B/C), and aisles allocated per BinKey PROPORTIONAL to each band's SKU footprint — so the hot A-band is a SMALL aisle fraction and the cold C-band is many rarely-visited aisles (batches skip them). Disabled ⇒ maps cleared (byte-identical).
