def _build_plan(args) -> list
The 6 store families, plus a fulfillment sub-catalog when --fulfillment-fraction > 0. Store shares scale to (1-F) and the fulfillment families sum to F, so shares stay relative. --freq-profile bell swaps the per-category freq specs for bell (normal) ones and gives fulfillment SKUs an equal-weight 3-normal mixture; 'uniform' keeps the baseline plan.
