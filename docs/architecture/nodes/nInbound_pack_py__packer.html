def packer(order, quantity: int, deliveries=None) -> list
The injectable packer the Inventory Manager's broker seam consumes. One callable covering both arrival shapes — `deliveries` is the split (or None for one whole delivery), exactly the contract `_release_to_stock` has always had. The driver binds this as `mgr.packer`; the manager's own default packs the identical unit stream without producing `LoadPlan`s, so binding this changes RECORDS, never units.
