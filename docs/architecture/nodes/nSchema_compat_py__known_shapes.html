def known_shapes(family: str) -> dict
`{schema_id: shape}` for every id this family vets, as far as it is recoverable. The DECLARED shape is always present (it is built from the writer's DDL); historical ids come from the committed store. Missing ones are reported by `unrecoverable_ids`, not silently dropped — see the module docstring.
