def structural_bin_floor(handlings, categories, aisle_width, aisle_height) -> tuple[int, int]
(aisles, bins) the STORE cannot go below, for any catalogue: one aisle per bucket. Buckets are the handling x category x tier cross-product, so this floor is a property of the CONFIGURATION, not of the SKUs — capping SKUs does not lower it. `_apply_caps` never trims a bucket below one replica (every SKU must be placeable), so a `--s-max-bins` under this number is unachievable by construction. Exposed so a CLI can say so in milliseconds instead of mid-build, per pair, after the inventory load.
