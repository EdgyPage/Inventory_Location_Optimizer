def pick_rows(events, batch_id, batch_start, crew, *, shift_seconds: float=DEFAULT_SHIFT_SECONDS, first_seq: int=0)
Merged-stream rows for one batch's pick events. `events` carry ABSOLUTE times already — the arm hands every picker the batch epoch as its start — so `t_abs` is `e.time` and `t_local` is the offset from `batch_start`. `crew` supplies the role, the mode and the uid space; `e.picker_id` is the dense per-crew id and becomes `actor_local`, with `actor_uid` its crew-offset twin. A picker id outside the crew raises rather than being written under someone else's uid.
