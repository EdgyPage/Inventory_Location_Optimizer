function paint_overtime

def paint_overtime(strategies, S, m, baseline, out_dir_path, *, view, agg=False)
Render one over-time metric in one view and return the saved path (or None when nothing could be drawn). view='absolute': every strategy in presentation units, baseline in BASELINE_STYLE. view='percent' : per-batch % improvement vs the baseline strategy, aligned on the metric's own x — the baseline IS the zero line, so it is drawn as a reference line, not a series. agg=True labels the aggregate stage (values are already ×-baseline normalized upstream; the absolute view is skipped there by the caller).
