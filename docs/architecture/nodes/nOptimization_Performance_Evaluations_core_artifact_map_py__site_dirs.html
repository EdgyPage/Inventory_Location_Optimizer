def site_dirs() -> tuple
Every out_subdir a SITE-scope evaluation writes into, under `<pair>/_site/`. Flat, like `run_dirs()` and for the same reason rather than by copying it: the site stage's jobs are one per PAIR, so no two workers share an output root and there is no wipe race for the shared-top ownership rule to arbitrate. `prepare_site_dir` wipes the root once and creates these under it.
