def affinity_matrix(self, min_lift: float=1.5, max_lift: float=5.0, max_per_group: int=500) -> AffMatrix
Return per-pair lift values for within-(handling, category) SKU pairs. SKUs are grouped by storage_type — only items that share the same handling and category can be co-located, so cross-group lift is always zero. Each group is capped at max_per_group SKUs to keep the matrix sparse enough for batch sampling at warehouse scale.
