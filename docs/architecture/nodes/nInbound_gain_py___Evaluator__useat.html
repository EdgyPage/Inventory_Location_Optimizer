layer inbound · file Inbound/gain.py

def _useat(self, key, excluded, predicted, cache)
One placement's view of a tier for the uniform adapter: `[seats, predicted weight, the now-list]`. Both numbers are fixed at first touch and never recomputed as the tier is consumed. The units draw from ONE pool — the empties merged with whatever predicted clears the arm may see — and drawing uniformly from a mixed pool leaves its mix proportional in expectation, so the weight does not drift. What consumption changes is the SEAT COUNT, and that is the whole mechanism: it is the only way an inbound ordering can move a uniform arm's cost.
