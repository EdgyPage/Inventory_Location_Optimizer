def finish(self, rebuild) -> dict
Drain; on a break, rebuild + resubmit through `rebuild(cell) -> [Job]` up to `max_retries` times; return the jobs still not done, per cell (empty when clean). The order is the old `_supervise`'s: drain, and only on a break tear down, explain the death ONCE, build a fresh executor, and ask every cell with jobs left for its jobs again -- the driver's `rebuild` is where `mid_flight=True` is passed to the work-unit builder, so a torn coupled pair seen during a live retry is reported and not repaired (`workunits._reconcile_coupled_unit`).
