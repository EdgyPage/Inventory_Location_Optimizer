function _advance_lead_queue

layer wh_inventory · file Warehouse/inventory/inventory_reorder.py

def _advance_lead_queue(self) -> None
One batch elapsed: decrement pre-existing in-transit orders only. Runs BEFORE `_fire_reorders`, which is what stops an order fired this batch from being decremented in the same batch it was placed. The tick is one BATCH, not one second -- see `LEAD_TIME_UNIT` above for why that is a decision and what would change it.
