def _aisle_index_for_unit(aisle_index, unit, minimize: bool)
(best_D, best_bin_map) — one extremal-D representative bin per aisle for *unit*, read from the manager's pre-sorted secondary index (the fast-path twin of Inventory_Manager._candidates; this identical block used to sit inline at 3 sites). Resolves the unit's BinKey tier exactly as _candidates does: singleton -> its one bucket; tiered families (pallet / fulfillment) -> the smallest non-empty tier >= the unit's own, via the unit's OWN size table (fulfillment sizes are ff_*, absent from the pallet _SIZE_RANKS — a pallet-only lookup would silently drop every fulfillment unit). minimize picks each aisle deque's min-D head, else its max-D tail (sorted ascending). Returns ({}, {}) when no tier has bins.
