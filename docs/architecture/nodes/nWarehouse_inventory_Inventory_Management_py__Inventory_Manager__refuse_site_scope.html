def _refuse_site_scope(self, name: str, instead: str) -> None
Raise when a LEAF is asked a question only the SITE can answer. One place, six callers, one message shape: `name` is what was asked and `instead` is what a caller at the right scope asks instead. A method rather than six copies of the raise, because six spellings of one rule is six things to keep in step — and because the refusal is what the site-scope flag exists for, so it should be one readable thing.
