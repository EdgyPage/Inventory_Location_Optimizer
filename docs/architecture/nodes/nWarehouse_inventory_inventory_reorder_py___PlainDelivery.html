class _PlainDelivery
The default packer's per-delivery record: the unit stream and nothing else. What `_release_to_stock` observes from a plan when no packer is bound is exactly `.units` (a dock that would count the plans only exists when the driver also binds the rich packer) — so this is the whole flag-off contract, and the unit stream is byte-identical to `Inbound.pack.receive`'s by construction: both call `viable_storage_units` once per delivery quantity.
