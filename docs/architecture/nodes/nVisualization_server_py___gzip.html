def _gzip(response)
Compress large JSON in flight. Stdlib only — no middleware dependency. These payloads are highly repetitive JSON and compress ~10x: the colour authority (`/api/final_home`, ~70k SKUs) drops from ~6 MB to a few hundred KB, and a drill-in aisle from ~230 KB to ~25 KB. Run-scoped payloads are fetched once per run, but the viewer opens two of them side by side and the difference is a visible pause.
