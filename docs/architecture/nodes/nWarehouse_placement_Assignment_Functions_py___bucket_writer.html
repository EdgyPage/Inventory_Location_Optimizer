How this pool moves a head: the mapping's own `writable`, or plain indexing. A pool opened over a SHARED template (`frozen_tier._CowAisles` / `_CowBuckets`, which the gain evaluator's rounds open over) must clone the one cursor a take moves rather than mutate the template every other open is reading. A pool opened over a plain dict -- every wave placement, every eager build, every test -- owns its buckets outright and indexes them. Resolved ONCE per open, so the hot path is a bound-method call either way and no `getattr` per take.
