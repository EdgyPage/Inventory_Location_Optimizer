def next_guess(points: list) -> float
The line count to rescale at next, from this channel's `(n_in, n_out)` history. `n_out = g(n_in)` is monotone DECREASING: more lines a day means more stock, a bigger warehouse, more travel per pick and so fewer lines the crew can fill -- and its gain is above one on a real catalogue (the reference pair's fulfillment section went 1,818 -> 14,832 -> 4,048 -> 10,797 under plain iteration). So the plain iterate is used only until the root of `f(n) = log g(n) - log n` is BRACKETED (one point with `f > 0`, one with `f < 0`); from then on the next guess is the secant of `f` in log-space between the two bracket ends, pulled to the log-midpoint when it lands within 5% of either end (the one-sided stagnation regula falsi is known for). Every later evaluation shrinks the bracket, so the loop converges on any monotone map.
