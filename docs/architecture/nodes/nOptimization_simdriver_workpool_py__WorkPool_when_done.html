def when_done(self, cell, keys, callback) -> None
Run `callback()` on the parent thread once every `(cell, key)` in `keys` has RESOLVED -- succeeded OR failed, because "the config stage is over" is true either way and the aggregate stage must not wait forever on one errored leaf. Fires at most once, from inside `absorb`/`drain` (or immediately if already satisfied). The callback may submit more jobs.
