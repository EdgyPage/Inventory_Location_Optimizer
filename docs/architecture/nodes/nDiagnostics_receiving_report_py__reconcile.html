def reconcile(db_path: str, run_id: int | None=None) -> dict
Cross-check one sim DB's receiving surface. Returns a dict; never raises on content. `run_id` None means every run in the file, which is what a per-arm DB holds anyway. A DB with no receiving activity is a PASS with `active=False` — every run before this feature, and every run that did not ask for a crew. That is not the same as a failure, and conflating them would make the tool useless on exactly the runs it should be quiet about.
