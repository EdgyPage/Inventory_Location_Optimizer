@dataclass(eq=False)
class Law
A model BOUND to one object's coefficients: what that object charges for one event. The form a cost class carries as its `closed_form` attribute (`PutawayCost`, `UnloadCost`, `PickConfig`): `model` is the law's equations, `fixed` the object's own coefficients bound to their symbols, `output` the equation whose value is the charge. What is left unbound is the EVENT -- where the bin is, how much is moved, how heavy it is -- and `evaluate` takes exactly that: `PutawayCost(...).closed_form.evaluate(x=..., y=..., q=..., ...)`.
