def load_yard_trailers(path: str, run_id: int) -> list
Every trailer row this run recorded, in dispatch order. `[]` on a pre-yard vintage. RAW STAMPS. No span, no detention day, no overage — those derive at analysis against the run's recorded threshold, which is what makes a finished run's fee axis re-reportable without re-simulating. An empty list is also the honest answer for an inbound-off run: the table exists, and nothing stood in a yard.
