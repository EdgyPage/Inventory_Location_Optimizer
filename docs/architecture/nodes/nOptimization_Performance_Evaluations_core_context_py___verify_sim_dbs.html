def _verify_sim_dbs(strategies, log: logging.Logger) -> None
Refuse to build a context over an unvetted sim DB. Raises `UnsupportedSchema`. One check per DISTINCT file, ~10 PRAGMA round trips each. Measured at 28 ms per sim DB on the external results drive, so ~1 s for a 34-arm config — small beside the `batch_stats` load it guards, and paid once per context because `run_analysis` memoizes contexts per (config, focus) in `_CFG_CTX`. Not worth a cache of its own.
