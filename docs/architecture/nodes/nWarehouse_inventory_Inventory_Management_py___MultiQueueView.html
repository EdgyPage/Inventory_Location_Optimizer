class _MultiQueueView
A read-only, age-ordered view across split put-away streams. `_stock_queue` was a single deque that three external consumers iterate and measure (`Diagnostics/bucket_fill.py`, the runner's queue-depth ledger, and the conservation check). Once the streams split there is no one deque to return, and returning a merged COPY would let a caller mutate it and lose the write in silence. This is iterable and sizeable and nothing else, so the mutation fails at the attribute rather than at the consequence. Merged by arrival age, so a consumer asking "what is waiting, oldest first" gets the same answer it always did rather than one queue's contents followed by another's.
