def adopt(doc: dict, *, label: str | None=None, source_fp: str | None=None, commit: str | None=None, created: str | None=None) -> str
Store `doc` and make it the head, recording its provenance. Returns its schema id. Idempotent: adopting the current head only refreshes the mutable `source_fingerprint`. The previous head becomes the new entry's `parent`, which is what restores the ordering that hashes inherently lack.
