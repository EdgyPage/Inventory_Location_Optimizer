def accept(self, item, dur: float) -> None
The canonical handoff for ONE unloaded unit: ledger flip, labour, queue. `position = on_hand + queued + deferred` never wobbles, because the three ledger moves and the queue entry happen together here. Takes `dur` and not the whole `(t0, dur, w)` record: `t0` and `w` are fields of the DOCK's row, and the dock is the coordinator's — handing them to a leaf would be two dead parameters plus an invitation to write the row twice.
