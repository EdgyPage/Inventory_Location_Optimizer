def dispatch(self, now_s: float) -> None
Send the declaration up to `day x units_per_day` units, cumulatively, at `now_s`. Whole lots: a lot is one SKU's declared level, and splitting it would invent a partial shipment the declaration never made. The quota is cumulative so a large lot that overshoots one day's share is paid back by the next day sending less.
