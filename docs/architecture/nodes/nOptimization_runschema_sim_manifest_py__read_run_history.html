function read_run_history

layer opt_runschema · file Optimization/runschema/sim_manifest.py

cross-layer
def read_run_history(base_dir: str) -> list
The launch records for one run root, oldest first. `[]` when there are none. Tolerant of a truncated or hand-edited file: this is a LEDGER, and a reader that raised on a malformed one would take a whole campaign's history with it. A file that cannot be parsed reads as no history, and the next append starts a fresh list beside it.
