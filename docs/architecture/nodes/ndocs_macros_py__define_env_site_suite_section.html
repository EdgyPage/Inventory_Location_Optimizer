The SITE-scope figure blocks for one run/inventory variant — the figures a COUPLED run renders once for the site (its site-scope figure folder), not once per channel leaf. `full_suite_section` composes `images/{run}/{inv}/{cfg}/{fname}`; a site figure has no config, so it gets its own path, tied to site_tree's `site_figure_png` template by `Tests/architecture/test_site_tree.py` and to the `site` evaluation scope by the figure-registry test. Empty on an uncoupled experiment, whose manifest curates no `site_suite`.
