def aisle_geometry() -> tuple[int, int]
(width, height) of one aisle in physical units, read at CALL time. A FUNCTION, not two module scalars, and deliberately: the pair used to be `aisle_width_for(50)` / `aisle_height_for(10)` evaluated at import, so a CLI override could never reach them. That is the `_INITIAL_FILL` defect this project has already shipped once -- a run misreporting its own sizing in its own warehouse DB -- and `Tests/unit/test_config_reaches_the_worker.py` mutates the CONFIG key and calls every accessor twice to keep it from coming back. PARENT-SIDE. The warehouse is planned before any worker exists, so this is not in the worker payload; it is listed in that test's `PARENT_ONLY` with the reason.
