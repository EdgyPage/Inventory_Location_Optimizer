def pmf(self, upto: int) -> np.ndarray
P(q = i) for i = 0..upto-1: zero at i = 0, `P(X <= 1)` at i = 1 (the floor folds the Poisson's zero into one unit), the Poisson mass above. The lead-aware fill (`simconfig/coverage._served_under_lead`) convolves it; the founding family has a vectorised fast path there and this is the row-by-row form any family answers.
