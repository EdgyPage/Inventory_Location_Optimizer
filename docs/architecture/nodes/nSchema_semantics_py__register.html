def register(family: str, semantics: dict, covered: tuple) -> None
Declare a family's column semantics and which tables are COMPLETELY tagged. `semantics` is {table: {column: Col | ByDiscriminator}}, keyed exactly as `Family.declared_shape()['tables']` keys them. `covered` is the gate's scope: every column of a covered table must be tagged, and every tag must name a real column.
