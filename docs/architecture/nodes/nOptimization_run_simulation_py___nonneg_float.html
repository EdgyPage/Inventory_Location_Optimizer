def _nonneg_float(text: str) -> float
An argparse `type=` for a coefficient where 0 is the default and negative is nonsense. `swap_coef` is validated nowhere else -- not in `PutQueueSpec.__post_init__`, not in `PutQueue`. A negative value makes a cart swap REDUCE the duration of the put it precedes, and a negative total moves the crew clock BACKWARD, which makes `crew_clock.can_start` true again after the whistle has already blown. None of that raises anywhere.
