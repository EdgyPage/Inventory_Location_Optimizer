function resolve

layer schema · file Schema/identity.py

def resolve(con: sqlite3.Connection, family: Family, *, pinned: str | None=None, verify: bool=False) -> tuple
Resolve the schema id of `con`. Returns `(schema_id, source)`. With `verify=True` the id is always re-derived and checked against whatever was stamped or pinned; a disagreement means the file was migrated after it was written, and raises. The stamp is provenance, but the OBSERVED shape is what queries must be planned against.
