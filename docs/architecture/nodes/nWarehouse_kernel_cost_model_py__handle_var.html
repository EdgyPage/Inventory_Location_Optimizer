def handle_var(weight: float, volume: float, weight_coef: float, volume_coef: float, weight_fn: str='log', volume_fn: str='log') -> float
Per-unit weight/volume handling term v_s = pw·fn_w(w) + pv·fn_v(v) (no intercept, no quantity). fn defaults to natural log (the original behaviour); other base functions (linear / sqrt / pow:p / log:b) are honored so a config's pick_weight_fn/pick_volume_fn actually changes labor. The transforms clamp w/v internally (log→≥1, sqrt/pow→≥0).
