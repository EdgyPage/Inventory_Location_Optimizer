def viz_cache_path(base_dir: str, cell: str, pair: str, config: str, channel: str | None, strategy: str) -> str
Where the derived sidecar for one arm lives. ``<run_root>/_viz/<cell>/<pair>/<config>[/<channel>]/<arm>.viz.db`` — under the driver's reserved ``_`` prefix (``runschema.schema.RESERVED_PREFIX``), which every tree walker skips. NOT ``sim_<arm>.viz.db`` beside the sim DB: that name satisfies all three predicates of ``runlayout._sim_dbs_in`` (starts with ``sim_``, ends ``.db``, does not end ``.keyframes.db``), so it would surface as an extra ARM through ``resolver.sim_dbs()`` and crash ``Diagnostics/replay_run.py`` on a table it does not have.
