def _nonneg_int(text: str) -> int
An argparse `type=` that rejects negatives but ALLOWS zero. `--recv-crew-size 0` is meaningful -- it is the off switch, and the default -- so unlike `_positive_int` below, zero passes. Negative does not: it would reach `crew_clock.new_clocks` and raise three layers down, or worse, be swallowed by a truthiness guard on the way.
