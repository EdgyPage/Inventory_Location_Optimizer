def source_fingerprint(repo_root: str=_REPO_ROOT) -> str
Hash of every shape-defining source (path + content, CRLF-normalised, MISSING-marked). THE ALGORITHM IS SHARED NOW, not copied: `Schema.fingerprint.of_files` is the one implementation, and `runschema.contract` folds the same helper into the first half of its own fingerprint. It was a copy until `architecture-drift/05`, and it had already drifted -- `contract` grew a SECOND input class (`SHAPE_SOURCE_DIRS`, for auto-discovered files) and this copy did not, which is what made the honesty test fail. THIS STORE HASHES FILES ONLY, and that is correct rather than an omission: the profiles tree has no auto-discovered directory in its shape. A directory half here would hash nothing and read as parity.
