function _span_index

layer visualization · file Visualization/readers/base.py

def _span_index(self) -> sqlite3.Connection | None
An open sidecar, but ONLY when its `bin_span` came from the bin-mutation log. A v1 sidecar, or one rebuilt from the keyframes because the arm predates the log, holds spans on the keyframe grid. Reading those as if they were exact between keyframes is precisely the error this whole change removes, so the source is checked, not assumed.
