def _channel_runs_for(inventory) -> tuple[bool, list[tuple]]
Plan the channel-runs for one catalog. Store and fulfillment sweep their OWN config sets independently (a UNION, not a cross product): every STORE_CONFIGS entry drives a store channel-run, and — only when the catalog is mixed (contains fulfillment units) — every FULFILLMENT_CONFIGS entry drives a fulfillment channel-run. A store-only catalog yields just the store runs (byte-identical to the pre-fulfillment pipeline). Returns (mixed, [(channel, cfg), ...]) where each channel carries its own pick cost + pool.
