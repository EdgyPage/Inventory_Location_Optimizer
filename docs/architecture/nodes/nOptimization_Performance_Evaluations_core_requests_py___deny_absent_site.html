Every file a SITE request reads has to be on disk: the site DB AND both leaves'. Two separate absences with one message shape. A missing site DB is a coupled run that received nothing (or was never coupled at all); a missing leaf DB is the same condition `_deny_absent` reports one scope down — and the site's denominators come from the leaves, so half a site is not a smaller site, it is a wrong one.
