def binkey_of(obj) -> BinKey
The 4-tuple BinKey of a StorageUnit or an Aisle.Bin (duck-typed like regime_of). Units read (handling, category) from their order's storage_handle_config plus their own (storage_size, unit_category) — Singleton's fixed 'singleton' label comes from Singleton.storage_size itself, so no special-casing. Bins read their four mirror attributes. One constructor for the key that used to be hand-built at ~8 sites.
