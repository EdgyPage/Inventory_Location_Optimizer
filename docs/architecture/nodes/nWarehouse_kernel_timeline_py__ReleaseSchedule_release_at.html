def release_at(self, index: int, ready_at: float) -> float
When batch `index` starts, given the arm is free at `ready_at`. NEVER EARLIER THAN `ready_at`. A schedule says when work may begin, not when a picker teleports: if the previous batch overran its slot, this batch starts late and the schedule has been missed. `missed_by` reports that rather than hiding it.
