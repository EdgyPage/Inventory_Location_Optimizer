One BatchStats per batch, version-adaptive. A VETTED file is served by the `batch_frame` named query (per-vintage overrides and optional-fill included), so a consumer of this loader is version-free without knowing it. An unvetted file — the cold archive `Diagnostics/replay_run.py` deliberately reads — falls through to the frozen pre-registry body below, byte-for-byte the historical behavior.
