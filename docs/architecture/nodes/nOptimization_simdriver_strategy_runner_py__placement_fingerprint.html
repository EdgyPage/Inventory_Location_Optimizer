def placement_fingerprint(bin_map: dict) -> str
A rename-proof hash of a placement: `bin_map[sku] = [(aisle_id, bayX, bayY, qty), ...]`. Sorted by SKU and by location, so two managers holding the same units in the same bins agree whatever order they were filled in; sixteen hex digits, the size of the geometry fingerprint it sits beside. An empty placement hashes to a fixed value rather than raising: an arm that placed nothing still stamps.
