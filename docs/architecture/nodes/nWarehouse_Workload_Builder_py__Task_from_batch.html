function from_batch

layer warehouse_core · file Warehouse/Workload_Builder.py

cross-layer
@staticmethod
def from_batch(batch: Batch, warehouse: Warehouse, manager=None, cart: type[StorageCart]=StoreCart) -> list[Task]
Decompose a Batch into one Task per aisle. For each SKU in the batch, singleton bins are drained before pallet bins so that forward-pick locations are always preferred over reserve locations. If manager is provided its pre-built _sku_singleton_bins/_sku_pallet_bins dicts are used directly, skipping the O(N_all_bins) warehouse scan that would otherwise rebuild the index on every batch.
