Per (batch, aisle) rollups on the KEYFRAME grid — the pre-log fallback. Occupancy is only known at keyframes, so a non-keyframe batch inherits the nearest keyframe at or below it — the same rule `state_at` uses without a log, and it is why `home_match` and `occupied` step rather than glide between keyframes.
