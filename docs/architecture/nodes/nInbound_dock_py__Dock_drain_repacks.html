def drain_repacks(self) -> list
This batch's repack records (ADR-0003), and start the list over. DOES NOT RESET THE CLOCKS, and that is the whole difference from `drain_records`. Both streams are charged against the same crew on the same batch-local clock, so exactly one of the two drains may restart it; a second reset would rebase the surviving stream's `t0` against a clock that had already gone back to zero. The reset stays with `drain_records`, which is the one every dockful run makes.
