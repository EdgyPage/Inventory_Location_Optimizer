def _owner_of(self, abs_path: str) -> str | None
Which artifact a concrete path belongs to — MOST-SPECIFIC template wins. A wildcarded `{strategy}` happily glob-matches `sim_x.keyframes.db`, because a template placeholder cannot know that no arm name contains a dot. Rather than encoding that (false-in-general) fact, ownership is decided the way preflight's observe stage decides it: every template that matches is a candidate, and the one with the MOST literal characters — the most specific claim — owns the path. `sim_{strategy}.keyframes.db` out-literals `sim_{strategy}.db`, so a keyframe sidecar is never a sim DB.
