def _rederive_plan(path: list, items: dict[int, int]) -> list[int]
Per-bin quantities for a `Task` built without an explicit plan. The same greedy `from_batch` uses -- walk the path, take what the bin has up to the SKU's remaining demand -- so a hand-built Task behaves like a real one. It can pick a DIFFERENT distribution than `from_batch` would when the path order differs from the drain order, which is exactly why the real caller passes its plan instead.
