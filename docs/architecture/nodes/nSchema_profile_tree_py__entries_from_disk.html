def entries_from_disk(run_dir: str) -> dict
Descriptor `profiles` entries derived from a run dir the CALLER JUST WROTE. For generators whose write path does not thread per-side metadata through one loop (the legacy suite; the preflight canary): the generator claims what it wrote by walking its own output. This is NOT backfill — a generator deriving its own just-written tree is the writer speaking; deriving someone else's old tree would be fabricated provenance, and stays banned. Sides without a params.json record `params_digest: None` (the canary writes none) — absence stays honest.
