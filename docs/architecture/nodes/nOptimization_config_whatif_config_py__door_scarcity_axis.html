function door_scarcity_axis

layer opt_config · file Optimization/config/whatif_config.py

def door_scarcity_axis(policies, levels=PHASE2_DOOR_LEVELS, *, reference_doors=True)
The phase-2 axis for `policies` at each door count in `levels`, cells suffixed `_d<doors>`, plus (when `reference_doors`) the policies at the campaign's own four doors under their campaign names -- so every scarce cell has its four-door twin in the same matrix and a door count is read as a DIFFERENCE, never as a level on its own. Built from `phase2_inbound_axis(doors=...)`, which already threads the count to the dock.
