def best(available, ladder)
The first capability in `ladder` whose name is available, else None. `ladder` is ordered BEST-FIRST by the consumer, because "best" is a question about what is being asked: an exact end-of-batch source beats an approximate one for occupancy, and the ordering is not a property of the capabilities themselves.
