def run(base_dir, baseline='fifo', baseline_initial='match', reference=None, pairs='sum', log=None)
Engine: cross-cell throughput / labor-hours over base_dir; write whatif_labor.csv/json + the four PNGs, and return the CSV path. Importable so the analysis hub calls it in-process (no argv). `pairs` in {'sum','median'} blends the catalogs; a single-cell run still emits the CSV/JSON (its cross-cell deltas are empty).
