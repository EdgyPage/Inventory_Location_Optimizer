def gain_vs_base(hrs, items, base_hrs, base_items)
(grid_hours, delta_items, gain_pct) — this arm's lead over the baseline at matched time. Both curves are interpolated onto a shared grid spanning only the hours BOTH actually cover, so the comparison never extrapolates past the shorter run. gain_pct is the area between the curves over the baseline's own area on that grid, which is the honest "how far ahead, on average".
