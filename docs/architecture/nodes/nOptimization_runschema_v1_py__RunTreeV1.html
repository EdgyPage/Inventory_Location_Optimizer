class RunTreeV1
Resolver for a v1 run tree. Construct via ``runschema.resolver_for(base_dir)``. Every accessor returns an ABSOLUTE path (or an iterator of them). Existence is NOT implied — optional artifacts legitimately do not exist on some runs (see LEVELS/ARTIFACTS `condition`), so callers check `os.path.exists` where it matters.
