def _assignment_of(arm_key: str) -> str
The assignment rule inside an arm key — what `core.baseline` matches the baseline on. An arm key is `<initial>_<assignment>[_<reslot>]`, and the baseline declaration selects on `assignment == 'fifo'`. A site's members are arm PAIRS, which carry no such field of their own, so the store half's rule is lifted onto the pair: the diagonal is rank against rank and the reference pair is `fifo`/`fifo` (site-dock 06), so the half naming `fifo` names the reference pair. Falls back to the whole key, which makes the baseline resolution fall back POSITIONALLY and say so — never silently onto another pair.
