def _line_pmf(lines: list, upto: int) -> np.ndarray
`P(q_s = i)` for `i = 0 .. upto-1`, one row per line law -- 0 at `i = 0` (a line always demands at least one unit). The founding family is evaluated in one vectorised log-space pass (`max(1, Poisson(λ))`: `P(q = 1) = e^{-λ}(1 + λ)`, the Poisson mass above); any other family falls back to the law's own `pmf`, row by row, so a second family prices correctly the day it is stamped and merely loses the fast path.
