Pick-time cost model (LaTeX) with this config's calibrated coefficients. Matches Warehouse/picking/Pick.py: t_pick = M(y)·(t0 + q·t1 + q·h) + c_cart·1[cart swap] where t1 is the per-item charge (ADR-0001). An archived config WITHOUT a `pick_per_item` key predates the charge: it ran the model without the term, so the term is rendered absent rather than at this checkout's default — the page describes the run, not the current code.
