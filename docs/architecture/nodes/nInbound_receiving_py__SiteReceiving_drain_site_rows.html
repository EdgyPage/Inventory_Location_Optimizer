def drain_site_rows(self) -> list
This drain window's SITE-scoped yard rows, and start the list over. A coupled drain's `(yard_start, free_doors_start, yard_end, remainder)` belongs to neither leaf -- it is a statement about the site's trailers and the site's doors -- so `receive` parks it here instead of handing an arbitrary leaf a number that reads as its channel's. Nothing consumes this yet; `<pair>/_site/inbound_<pair>.db` is the declared home and its contract bump is the next ticket's.
