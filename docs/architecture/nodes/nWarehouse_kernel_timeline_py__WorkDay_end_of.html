function end_of

layer wh_kernel · file Warehouse/kernel/timeline.py

def end_of(self, index: int) -> float
The instant the day CLOSES -- which is the next day's start. Half-open by construction: an instant exactly at `end_of(i)` belongs to day i+1, and `index_of(end_of(i)) == i + 1`. Anything else double-counts the boundary instant.
