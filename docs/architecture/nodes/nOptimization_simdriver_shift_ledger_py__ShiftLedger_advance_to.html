def advance_to(self, day)
Move to `day`. Returns the snapshot of the day that just ENDED, or None. None on the first batch (no previous day exists) and within a day. On a boundary the returned tuple is `(day, standing, last_finish, cut)` for the day that ended -- `_shift_close_out`'s exact parameter order -- and the new day is opened uncut with no finish. Days need not be contiguous: an empty day still consumes a release slot, and nothing is invented for the days in between.
