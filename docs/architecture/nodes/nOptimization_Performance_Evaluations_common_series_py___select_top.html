def _select_top(strategies, S, top_n, top_by)
Choose which strategies the top/ plot shows. 'global' → the top_n strategies overall (by steady-state throughput). a dim → the top_n WITHIN each value of that dim (initial/assignment/reslot), so the comparison isn't dominated by one family (e.g. optimal-start). Returns (selected_strategies, group_of_key) where group_of_key maps key→group label ('' for global).
