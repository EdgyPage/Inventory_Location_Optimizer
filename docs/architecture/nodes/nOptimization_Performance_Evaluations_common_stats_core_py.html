Optimization.Performance_Evaluations.common.stats_core
Statistical machinery for the significance suite (verbatim from the retired Stats_Analysis): metric specs, multiple-comparison correction, paired effect sizes, descriptives, the omnibus+pairwise test runner, and the by-initial grouping helpers. The four plot primitives that consume these results live in stats/plots.py.
