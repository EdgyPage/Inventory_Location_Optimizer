cross-layer
def load_free_index(path: str, run_id: int) -> list
The free index per bucket per batch, in (batch, key) order. `[]` on a pre-table vintage, which is "the depth was never recorded per bucket", never "no bucket had a free bin". Every `free` is a LEVEL re-measured per batch: `sum()` over a bucket's rows restates the same free bins once per batch (the `recv_cut` scar). The statistics that mean something are per bucket over a window -- minimum, mean, and the drawdown from the record's stamped setup `free` -- which is how the rework clause reads it.
