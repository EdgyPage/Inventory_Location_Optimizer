class Mode(_Named)
How the actor moves: on foot, or on a machine. The axis that decides speed. A machine drives faster along an aisle than a person walks and lifts differently up a rack — and because x (horizontal run) and y (vertical lift) are separate quantities, a machine is a DIFFERENT `SpeedProfile` from a walker, not a scaled one.
