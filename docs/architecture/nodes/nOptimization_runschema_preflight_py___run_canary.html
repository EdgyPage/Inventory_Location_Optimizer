def _run_canary(workdir: str, name: str, *, spec: str, mixed: bool, echo=print) -> str | None
Run one canary simulation in a SUBPROCESS; return its run-root dir (None on failure). Isolation is by environment, not new flags: PROFILE_INPUT_DIR / COMPARISON_OUTPUT_DIR are already the driver's input/output roots (sim_config), so the real results drive is never touched. ILO_SKIP_PREFLIGHT stops the child from re-entering this module.
