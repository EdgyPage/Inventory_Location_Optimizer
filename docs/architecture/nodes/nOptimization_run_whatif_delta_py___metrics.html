def _metrics(db: str)
Steady-state means (last WIN batches) of the four success metrics from batch_stats: task_ms = task makespan = Σ task time = total labor (metric a) batch_ms = batch makespan = last-picker finish (wall-clock) (metric b) thr_batch = items / batch makespan (metric d) thr_task = items / task makespan (metric c) New runs carry task_makespan/thr_task as columns; legacy DBs fall back to the task_stats join.
