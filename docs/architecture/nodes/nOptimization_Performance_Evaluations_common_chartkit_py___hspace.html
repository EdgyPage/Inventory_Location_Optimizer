def _hspace(panel_h: float) -> float
Row gap as a CONSTANT physical distance, expressed in matplotlib's fraction units. `hspace` is a fraction of the mean axes height, so a tall panel gets a proportionally taller gap: a 17-category ladder at ~6 in per panel opened a 2.5-inch band of white between rows, which reads as two unrelated figures stacked in one file. The gap has to clear one x-label plus the next row's title, and that is a fixed number of inches no matter how tall the panels are. Capped at the historical 0.42 so nothing SHORTER than the default panel moves — this only ever shrinks an oversized gap.
