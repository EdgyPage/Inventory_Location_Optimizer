Optimization.simdriver.cells
simdriver.cells — the what-if cell matrix: build/apply/inspect cells. A cell = a fixed choice of aisle-split × zoning × scheduler over one frozen inventory. _apply_cell mutates the SAME sim_config.CONFIG object (never rebound) so the change is seen everywhere; _build_cells names cells k{k}[_l{loss}]_{zone}[_{sched}].
