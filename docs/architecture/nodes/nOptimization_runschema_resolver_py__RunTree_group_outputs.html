def group_outputs(self, group: str) -> list[str]
Every EXISTING file declared under a contract group tag, globs expanded. The tag is the unit of discovery, so a producer that emits a new document gets it staged and consumed with no edit at either end — which is what separates the group-driven stages from the ones that name their artifacts one at a time.
