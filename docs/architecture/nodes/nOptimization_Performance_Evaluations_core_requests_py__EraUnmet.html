class EraUnmet(Denied)
A refusal about the DATA ERA, not about a missing resource. Kept distinct from a plain `Denied` because the two call for different actions and a single bucket taught the reader the wrong one. A denial says a file was not there — re-run the stage, fix the path. This says the file IS there and cannot answer the question, because the run predates the column or never wrote the rows. There is no fixing that from the analysis side: the only honest routes are a new sweep on a vintage that records it, or the degraded form with the caveat said out loud. It reports under its own `[era]` summary line for the same reason. `[access]` counts INPUTS, and an era shortfall arriving in that column would read as a pipeline fault on a run that is simply older than the measurement.
