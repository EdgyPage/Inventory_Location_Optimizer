function _fire_settled

layer opt_simdriver · file Optimization/simdriver/workpool.py

def _fire_settled(self) -> None
Announce each newly settled cell exactly once. AFTER `_fire_continuations`, deliberately: a continuation may submit more jobs for its own cell (the analysis stage does), and a cell with a continuation still to fire is not settled. Announcing first would drop assets a resubmission needs. A cell can leave `_settled` on a REBUILD -- `submit` is called again for it after a broken pool -- so membership is re-derived rather than latched: the driver's handler is idempotent (a `dict.pop`), and a second announcement after a genuine resubmission is correct, not a bug.
