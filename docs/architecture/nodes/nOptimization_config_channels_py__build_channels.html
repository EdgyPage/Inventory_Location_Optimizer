def build_channels(store_pick_cfg: PickConfig, store_num_pickers: int, *, include_fulfillment: bool, ff_pick_cfg: PickConfig | None=None, ff_num_pickers: int=_FF_PICKERS, store_restocks: tuple[str, ...] | None=None) -> list[Channel]
Assemble the run's channel list. The STORE channel's cost is the run's own (swept) PickConfig, so store results are unchanged. The FULFILLMENT channel is appended only when the inventory has fulfillment items (``include_fulfillment``); it uses the walker cost + its own picker pool. ``store_restocks`` restricts the store channel to a subset of restock rules (None ⇒ full suite); fulfillment always runs the full suite.
