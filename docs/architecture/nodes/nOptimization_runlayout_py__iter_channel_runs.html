def iter_channel_runs(base_dir: str, marker: str='sim_meta.json') -> Iterator[ChannelRun]
Yield every channel-run dir under base_dir that contains *marker*. Store-only runs put the marker directly at <config>/; mixed-catalog runs put one per channel at <config>/<channel>/. Top-level entries starting with '_' (e.g. _aggregate/) are skipped. Order: sorted pair, then config, then channel.
