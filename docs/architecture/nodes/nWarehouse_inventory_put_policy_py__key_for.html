def key_for(policy: str | None, items)
Resolve a policy name to a `(item) -> float` key over THIS batch's waiting items. Returns None for `inherit` (or None), meaning the caller should use the placement pool's own precedence. Raises on an unknown name rather than silently inheriting: a typo in a swept configuration would otherwise produce a run that looks like a legitimate arm.
