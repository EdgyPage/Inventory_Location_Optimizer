Optimization/run_unload_ranking.py

layer optimization

Phase 2 -> phase 3 hand-off CLI: ranks a coupled phase-2 run's cells (unloading policies) per rule pair on total site labour (ss_prod_total summed over a unit's two leaves), ties inside the declared noise floor broken by site yard overage (frames._ydf), and writes unload_ranking.json at the run root; the twin of run_restock_selection.
