Tests/unit/test_cold_start_tie_break.py

layer tests

Fences _AislePrefIndex, the merged sorted array that answers cluster_map's COLD-START tie-break in O(log N + k) against the O(A) per-aisle scan it replaces -- the growing case, measured rising 3.0% to 14.4% of a scan already fitting k=1.99. The whole difficulty is the tie ORDER: `min` returns the FIRST element achieving the minimum, so equal gaps go to the earliest aisle in by_aisle ITERATION order, not the lowest pref or the lowest id -- so the collisions are CONSTRUCTED (the winner deliberately holds both the higher id and the higher pref) rather than hoped for, and a randomised leg interleaves consumption because the index is a third structure in multiset-sync.
