Optimization/runschema/preflight.py

layer opt_runschema

Proves the run-tree contract BEFORE a simulation: detects shape-defining source changes, runs two tiny canary sims (mixed 2-cell + store-only 1-cell, so optional levels are exercised both ways), validates the produced tree against the committed contract, and on a real change scaffolds the next version and rewrites the downstream orchestrator files.
