Inbound/receiving.py

layer inbound

the site's receiving coordinator: one dock, one yard, N leaves.

Owns the standing drain, which used to be the manager's `_receive_standing`. Reaches each channel's leaf through two public ports (`plan_lot`, `accept`) and never imports one: `Warehouse <-> Inbound` is forbidden both ways, so the driver binds it (`mgr.receiving`). That is what lets one dock serve two leaves.
